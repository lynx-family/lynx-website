## Structure

A single-value slider uses one thumb.

```tsx
<SliderRoot>
  <SliderTrack>
    <SliderIndicator />
    <SliderThumb />
  </SliderTrack>
</SliderRoot>
```

A range slider uses two indexed thumbs.

```tsx
<SliderRoot value={range}>
  <SliderTrack>
    <SliderIndicator />
    <SliderThumb index={0} />
    <SliderThumb index={1} />
  </SliderTrack>
</SliderRoot>
```
