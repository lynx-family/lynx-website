## Basic Usage

Use `<Input>` to render a single-line input field, and `<TextArea>` to render a multi-line text area.

## Structure

`Input` and `TextArea` can be used independently:

```tsx
<Input />
<TextArea />
```

Use the keyboard-aware parts when an input should remain visible above the
keyboard:

```tsx
<KeyboardAwareRoot>
  <KeyboardAwareResponder>
    <KeyboardAwareTrigger>
      <Input />
    </KeyboardAwareTrigger>
    <KeyboardAwareTrigger>
      <TextArea />
    </KeyboardAwareTrigger>
  </KeyboardAwareResponder>
</KeyboardAwareRoot>
```
