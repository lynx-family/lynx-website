## Structure

{/* prettier-ignore */}
```tsx
<TabsRoot>
  <TabsBar
    data={tabs}
    renderTabItem={(tab, index) => <TabsItem />}
  >
    <TabsIndicator />
  </TabsBar>
  <TabsPanel data={panels}>
    {(panel, index) => <PanelContent />}
  </TabsPanel>
</TabsRoot>
```
