# MDX Components Reference

This page serves as a reference for the custom components available in the Lynx documentation. You can import these from `@lynx`.

## Versioning

The page-level SDK indicator uses `since` from guide frontmatter and the site's
release configuration. Import `Since` from `@lynx` for requirements scoped
to local content in MDX:

```tsx
<Since since="4.3" />
```

Place a local indicator immediately below the heading or beside the content it
qualifies. Local indicators use a brand-colored icon and the soft Note background.

`Since` reads `latestStable` and `baseline` from the site's configuration by
default. Either prop can override its site value; omitted props still use the
site's settings. Without site configuration, it uses the SDK release metadata
with no display baseline. The examples below specify overrides to demonstrate
particular states. Guide frontmatter only needs `since`.

### Released

The stable indicator includes the **L** icon and a compact version label such
as **4.2+**, meaning this version and later.

```tsx
<Since since="4.2" latestStable="4.2" />
```

<div className="rp-not-doc">
  <Since since="4.2" latestStable="4.2" />
</div>

### Unreleased

The indicator still shows the minimum version with **+**. Its sparkle icon
signals an upcoming release. Hover or focus the capsule to see **Unreleased**.
Expand it to read the explanation and release notes link; the tooltip stays
hidden while expanded.

```tsx
<Since since="4.3" latestStable="4.2" />
```

<div className="rp-not-doc">
  <Since since="4.3" latestStable="4.2" />
</div>

### Page-level

When one SDK requirement applies to a whole guide, declare it in frontmatter:

```yaml
---
since: '4.3'
---
```

The theme renders a neutral indicator before the page title. Authors do not
need to add `Since` to the page body.

### Local Content

Pass children to group a version requirement with its explanation in a Note-style
block. The version replaces the generic Note title. Only the release explanation
collapses; the authored content remains visible.

```mdx
<Since since="4.5">

Heap snapshot collection currently supports QuickJS only.

</Since>
```

<Since since="4.5" latestStable="4.2">

Heap snapshot collection currently supports QuickJS only.

</Since>

Markdown export keeps the version, unreleased status when applicable, and children
inside one blockquote. Without children, the version and status are plain paragraphs.

### Display Baseline

Versions at or below `baseline` hide the HTML indicator. The first example
renders nothing; Markdown output still includes the version fact.

```tsx
<Since since="3.2" latestStable="4.2" baseline="3.2" />
<Since since="3.2" latestStable="4.2" baseline="3.2" format="markdown" />
```

<div className="rp-not-doc">
  <Since since="3.2" latestStable="4.2" baseline="3.2" />
</div>

<Since since="3.2" latestStable="4.2" baseline="3.2" format="markdown" />

When children are present, the baseline hides only the indicator. The content
block remains visible, including any platform, engine, or tooling restrictions:

```mdx
<Since since="3.2" baseline="3.2">

Platform requirements still apply.

</Since>
```

<Since since="3.2" latestStable="4.2" baseline="3.2">

Platform requirements still apply.

</Since>

## Callout & Alerts

Used to highlight important information. You can use standard Markdown syntax `:::type` for callouts.

```markdown
:::info
This is an info callout.
:::

:::warning
This is a warning callout.
:::

:::tip
This is a tip callout.
:::

:::danger
This is a danger callout.
:::
```

## Badges

### Platform Badges

Indicate platform support.

```tsx
<AndroidOnly />
<IOSOnly />
<WebOnly />
<HarmonyOnly />
```

<div style={{ display: 'flex', gap: '8px', flexWrap: 'wrap' }}>
  <AndroidOnly />
  <IOSOnly />
  <WebOnly />
  <HarmonyOnly />
</div>

### Status Badges

Indicate API or feature status.

```tsx
<Deprecated />
<Experimental />
<Required />
```

<div style={{ display: 'flex', gap: '8px', flexWrap: 'wrap' }}>
  <Deprecated />
  <Experimental />
  <Required />
</div>

### Runtime Badges

Indicate which thread the script runs on.

```tsx
<RuntimeBadge type="mts" />
<RuntimeBadge type="bts" />
```

<div style={{ display: 'flex', gap: '8px', flexWrap: 'wrap' }}>
  <RuntimeBadge type="mts" />
  <RuntimeBadge type="bts" />
</div>

### Version Badge

Indicates the Lynx version a feature was introduced.

```tsx
<VersionBadge v={2.5} />
<VersionBadge>2.5.1</VersionBadge>
```

<div style={{ display: 'flex', gap: '8px', flexWrap: 'wrap' }}>
  <VersionBadge v={2.5} />
  <VersionBadge>2.5.1</VersionBadge>
</div>

### Generic Badges

Standard Rspress badge.

```tsx

```

## Layout & Containers

### Platform Tabs

Organize content by platform.

```tsx
<PlatformTabs defaultPlatform="ios" queryKey="platform">
  <PlatformTabs.Tab platform="ios">iOS Content</PlatformTabs.Tab>
  <PlatformTabs.Tab platform="android">Android Content</PlatformTabs.Tab>
</PlatformTabs>
```

<PlatformTabs defaultPlatform="ios" queryKey="platform">
  <PlatformTabs.Tab platform="ios">iOS Content</PlatformTabs.Tab>
  <PlatformTabs.Tab platform="android">Android Content</PlatformTabs.Tab>
</PlatformTabs>

### Columns

Split content into columns. Pass `titles` prop for column headers.

```tsx
<Columns titles={['Left Column', 'Right Column']}>
  <div>Content for the left column.</div>
  <div>Content for the right column.</div>
</Columns>
```

<Columns titles={['Left Column', 'Right Column']}>
  <div>Content for the left column.</div>
  <div>Content for the right column.</div>
</Columns>

### Responsive Dual Column

A layout that switches to single column on smaller screens. Use `FlexItem` to control width.

```tsx
<ResponsiveDualColumn>
  <FlexItem minWidth={300}>
    <div>Left Content (min 300px)</div>
  </FlexItem>
  <FlexItem minWidth={300}>
    <div>Right Content (min 300px)</div>
  </FlexItem>
</ResponsiveDualColumn>
```

<ResponsiveDualColumn>
  <FlexItem minWidth={300}>
    <div style={{ background: 'var(--rp-c-bg-mute)', padding: '1rem' }}>
      Left Content (min 300px)
    </div>
  </FlexItem>
  <FlexItem minWidth={300}>
    <div style={{ background: 'var(--rp-c-bg-mute)', padding: '1rem' }}>
      Right Content (min 300px)
    </div>
  </FlexItem>
</ResponsiveDualColumn>

### Browser Container

Wraps content in a browser-like window frame.

```tsx
<BrowserContainer>
  <div style={{ padding: '20px', textAlign: 'center' }}>Browser Content</div>
</BrowserContainer>
```

<BrowserContainer>
  <div style={{ padding: '20px', textAlign: 'center' }}>Browser Content</div>
</BrowserContainer>

### CodeFold

Collapsible code block, optionally with an image.

````tsx
<CodeFold toggle>```ts console.log('Hidden code'); ```</CodeFold>
````

<CodeFold toggle>

```ts
console.log('Hidden code');
```

</CodeFold>
