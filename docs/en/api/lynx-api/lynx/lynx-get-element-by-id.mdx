# getElementById()

<APISummary />

## Introduction

getElementById is a method for finding elements' reference based on a specified id in the current [page](/guide/spec.html#page).
This method takes an id selector as the parameter and returns a reference to the corresponding element's reference.
Please note that this reference does not allow background threads to hold the elements;
background threads can only use this reference to [inter thread call](/guide/spec.html#inter-thread-call-or-itc) [element methods](/guide/spec.html#element-method) across threads,
and this reference does not affect the element's lifecycle.

## Syntax

```js
let element = lynx.getElementById(id);
```

### Parameter

#### id

A String type, the id selector of the element to be obtained.

### Return Value

Returns an `AnimationElement` reference. Lynx looks up the node when it processes a method call on the reference.

## Example

```js
let ele = lynx.getElementById('id');
```

::: tip

The target node must exist and match the ID selector when Lynx processes the method call.

:::
