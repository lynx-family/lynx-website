# lynx: unsubscribeSessionStorage() static method

<APISummary />

The `lynx.unsubscribeSessionStorage` method cancels a data change listener registered with [lynx.subscribeSessionStorage](./lynx-subscribe-session-storage.mdx) in the current WhiteBoard. Canceling the listener does not remove the cached data.

See [Share Data Across LynxViews](../../../guide/share-data-across-lynxviews.md) for sharing scope, native configuration, and lifecycle management.

## Syntax

```ts
lynx.unsubscribeSessionStorage(key, id);
```

### Parameters

#### key

The key for the cached data, used to retrieve data and listen for changes.

#### id

The ID for the data change listener. Use the ID returned by [lynx.subscribeSessionStorage](./lynx-subscribe-session-storage.mdx) to cancel the listener.

### Return Value

None (`undefined`).
