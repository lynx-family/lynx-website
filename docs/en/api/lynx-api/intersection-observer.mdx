# IntersectionObserver

<APISummary />

`IntersectionObserver` tracks how a target node intersects a reference area, accounting for clipping by ancestor nodes. Use it to detect when a node becomes visible or leaves the visible area.

## Instance method

[`IntersectionObserver.relativeTo()`](./intersection-observer/intersection-observer-relative-to.mdx)

Select the reference node with a `#id` selector.

[`IntersectionObserver.relativeToViewport()`](./intersection-observer/intersection-observer-relative-to-viewport.mdx)

Use the `LynxView` viewport as the reference area.

[`IntersectionObserver.relativeToScreen()`](./intersection-observer/intersection-observer-relative-to-screen.mdx)

Use the screen as the reference area.

[`IntersectionObserver.observe()`](./intersection-observer/intersection-observer-observe.mdx)

Select the target node with a `#id` selector and register a callback.

[`IntersectionObserver.disconnect()`](./intersection-observer/intersection-observer-disconnect.mdx)

Stop observing all target nodes.

## Example

This example observes how `#targetNode` intersects `#refNode` in the current `LynxView`.

```tsx
const observer = lynx.createIntersectionObserver(
  { componentId: '' },
  { thresholds: [0, 0.25, 0.5, 0.75, 1] },
);

observer.relativeTo('#refNode', { left: 10, right: 10 });
observer.observe('#targetNode', (entry) => {
  console.log(entry.intersectionRatio);
});
```

Call `observer.disconnect()` when you no longer need to observe the target.

## Precautions

- Call `relativeTo()` and `observe()` after the reference and target nodes have been created.
- On Android, child nodes of a horizontally scrolling `scroll-view` do not trigger callbacks while scrolling. Set [`flatten`](../elements/built-in/view.mdx#flatten) to `false` on the child node to trigger them.
