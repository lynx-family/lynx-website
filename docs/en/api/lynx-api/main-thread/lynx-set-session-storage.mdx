# lynx: setSessionStorageItem() static method

<APISummary />

The `lynx.setSessionStorageItem` method sets cached data in the current WhiteBoard. Only LynxViews that share this WhiteBoard can access the same data. Use [lynx.getSessionStorageItem](./lynx-get-session-storage.mdx) to retrieve it.

See [Share Data Across LynxViews](../../../guide/share-data-across-lynxviews.md) for sharing scope, native configuration, and lifecycle management.

## Syntax

```ts
setSessionStorageItem(key: string, value: object): void;
```

### Parameters

#### key

The key for the cached data. It can be used subsequently to retrieve the data or listen for changes.

#### value

The data object to be stored.

### Return Value

None (`undefined`).
