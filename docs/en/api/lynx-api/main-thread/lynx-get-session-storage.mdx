# lynx: getSessionStorageItem() static method

<APISummary />

The `lynx.getSessionStorageItem` method retrieves cached data from the current WhiteBoard. LynxViews that share this WhiteBoard can retrieve the same data. Use [lynx.setSessionStorageItem](./lynx-set-session-storage.mdx) to set it.

See [Share Data Across LynxViews](../../../guide/share-data-across-lynxviews.md) for sharing scope, native configuration, and lifecycle management.

## Syntax

```ts
lynx.getSessionStorageItem(key, (value) => {});
```

### Parameters

#### key

The key for the cached data, used to retrieve data and listen for changes.

#### callback

The callback function for retrieving cached data. The argument is the cached data object.

### Return Value

None (`undefined`).
