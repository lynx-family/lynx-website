## Introduction

Contributes a grid span to the grid item's placement.
If there are [`grid-row-start`](./grid-row-start) and [`grid-row-end`](./grid-row-end), this css property will be overridden.

## Notes

- When `grid-row-start` and `grid-row-end` specify two distinct grid lines, the row span is determined by the distance between those lines, and `grid-row-span` is ignored. The following item spans three rows:

  ```css
  grid-row-start: 2;
  grid-row-end: 5;
  grid-row-span: 1;
  ```

- Do not combine `grid-row-span` with `span <number>` in `grid-row-start` or `grid-row-end`. Both specify the row span and can override each other. The following declarations specify conflicting spans of three rows and one row:

  ```css
  grid-row-start: 2;
  grid-row-end: span 3;
  grid-row-span: 1;
  ```
