## Introduction

Contributes a grid span to the grid item's placement.
If there are [`grid-column-start`](./grid-column-start) and [`grid-column-end`](./grid-column-end), this css property will be overridden.

## Notes

- When `grid-column-start` and `grid-column-end` specify two distinct grid lines, the column span is determined by the distance between those lines, and `grid-column-span` is ignored. The following item spans three columns:

  ```css
  grid-column-start: 2;
  grid-column-end: 5;
  grid-column-span: 1;
  ```

- Do not combine `grid-column-span` with `span <number>` in `grid-column-start` or `grid-column-end`. Both specify the column span and can override each other. The following declarations specify conflicting spans of three columns and one column:

  ```css
  grid-column-start: 2;
  grid-column-end: span 3;
  grid-column-span: 1;
  ```
