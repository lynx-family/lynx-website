## Introduction

The `grid-row-end` CSS property specifies a grid item's end position within the grid row by contributing a line, a span, or nothing (automatic) to its grid placement.

## Syntax

```css
/* <number> values */
grid-row-end: 2;
grid-row-end: 3;

/* span  <number> values*/
grid-row-end: span 1;
```

### Values

- `auto`

  **Default value**. Is a keyword indicating that the property contributes nothing to the grid item's placement, indicating auto-placement, an automatic span, or a default span of `1`.

- `<number>`

  Grid item's end position. An integer value of 0 is invalid.

- span && `<number>`

  Contributes a grid span to the grid item's placement such that the row end edge of the grid item's grid area is n lines from the start edge.

## Formal syntax

```
grid-row-end = <number> | [span && <number>]
```

## Differences from the Web

- `<custom-ident>`, `span && <custom-ident>`, `<integer> && <custom-ident>?` are not supported.

## Notes

- When `grid-row-start` and `grid-row-end` specify two distinct grid lines, the row span is determined by the distance between those lines, and [`grid-row-span`](./grid-row-span) is ignored. The following item spans three rows:

  ```css
  grid-row-start: 2;
  grid-row-end: 5;
  grid-row-span: 1;
  ```

- Do not combine `grid-row-span` with `span <number>` in `grid-row-start` or `grid-row-end`. Both specify the row span and can override each other. The following declarations specify conflicting spans of three rows and one row:

  ```css
  grid-row-start: 2;
  grid-row-end: span 3;
  grid-row-span: 1;
  ```
