# `<markdown>`

<APISummary />

`<markdown>` renders Markdown content in Lynx, including headings, paragraphs, block quotes, lists, code, links, images, and tables. It also supports embedded Lynx views, typewriter animation, and text selection.

The host must integrate and register this native element. Run the examples in a Lynx Explorer build that includes `<markdown>`. See [Compatibility](#compatibility) for platform support of individual attributes and methods.

### Modify Styles

The inner elements of `<markdown>` are not Lynx elements, so they cannot be styled using CSS. However, we can use the `markdown-style` attribute to modify the styles of inner elements.

<Go
  example="markdown"
  webPreview={false}
  defaultFile="src/style/index.tsx"
  defaultEntryName="style"
  img="https://lf-lynx.tiktok-cdns.com/obj/lynx-artifacts-oss-sg/lynx-website/assets/markdown/style-30e2f2032899.webp"
/>

In the above code, we passed an object through the `markdown-style` attribute. This object represents the style configuration for all `normalText` elements (i.e., regular text) and `inlineCode` elements (i.e., inline code). In this case, we set the font size of all `normalText` elements to 25px and the font size of all `inlineCode` elements to 20px, with a color of red.

`markdown-style` is just such a series of tag-to-style configuration mappings. By using it, we can modify the style of a specific syntax. See [Stylesheets](#stylesheets) for the supported tags and their configuration options.

In the above code, we inserted a gradient color text by using `![](inlineview://mkd)`. The `mkd` view is a child view of `markdown`, and it contains the gradient color text we need.

inlineview can be set `vertical-align` to configure the vertical alignment. The default value is `baseline`, and in the above code, we set it to `center` to make the text align properly.

### Truncation

`markdown` comes with a built-in truncation feature. Whether to add an ellipsis can be set through the `overflow` property. The default value is `ellipsis`, which means an ellipsis will be added. Setting it to `clip` means no ellipsis will be added. Tables do not support adding ellipses.

You can control the maximum number of text lines through the `text-maxline` property, and control the maximum text height through the `height` style. When both are present, they will take effect simultaneously.

#### Text Fade Effect

If you want the text to fade out at the end of the typing instead of using a cursor at the end, you can set `customCursor` in `typewriterCursor` to "none" to disable the cursor, and then use `markdown-effect` to set the fade effect of the text.

<Go
  example="markdown"
  webPreview={false}
  defaultFile="src/typewriter_mask/index.tsx"
  defaultEntryName="typewriter_mask"
  img="https://lf-lynx.tiktok-cdns.com/obj/lynx-artifacts-oss-sg/lynx-website/assets/markdown/typewriter_mask-9c9c451d14d0.webp"
/>

In the above code, we added a text mask effect through `markdown-effect`. It will add a semi-transparent mask layer on the last 4 characters of the text.

Here we also listen to the `drawEnd` event, which is because `markdown-effect` will not be automatically removed after the typing is complete, but the `drawEnd` event will be triggered after the typing is complete, and in the callback of this event, we can clear `markdown-effect` to remove the fade effect of the text.

Like the cursor, when `content-complete` is set to `false`, the `drawEnd` event will not be triggered after the typing is complete. Therefore, the above code will remove the fade effect of the text after the content is complete **and** the typing is complete.

Long-press the text to start a selection. Provide your own menu and actions; enabling selection does not add a clipboard menu.

#### Implement a Menu

`getTextBoundingRect` returns page coordinates. Subtract the containing view’s `boundingClientRect` coordinates before positioning an absolute menu inside it. This example displays the menu; the following examples add button actions.

When the selected area changes, the `selectionchange` event will be triggered, and the event parameters will contain the start position and end position of the selected area. If the current selected area is empty, both the start position and end position will be -1. We can use this to determine whether to display or hide the menu.

After displaying the menu, we need to adjust the position of the menu based on the selected area. We can use the `getTextBoundingRect` method to get the position of the selected area. This method needs to pass in the start position and end position of the selected area, and the return value is a `TextBoundingRect` object. The object contains the total bounding rect of the selected area and the bounding rect of each line of the selected area.

```ts
interface Rect {
  left: number;
  right: number;
  top: number;
  bottom: number;
  width: number;
  height: number;
}

interface TextBoundingRect {
  boundingRect: Rect;
  boxes: Rect[];
}
```

Use the total bounding rectangle to center the menu above the selection:

#### Select a Paragraph or Sentence

`setTextSelection` takes coordinates relative to `<markdown>`. When selecting a paragraph from the center of a text bounding rectangle, subtract the markdown element’s page coordinates before passing equal start and end points.

By default, `markdown` only selects the character at the touch position when long pressed. If you want to select a paragraph or sentence, you need to adjust the selected area in the `selectionchange` event.

`setTextSelection` method also has a `selectionTextType` parameter. When the start and end positions are the same, this parameter will take effect. It is used to specify the type of selected text, which can be `char`, `word`, `sentence`, and `paragraph`.

By setting this parameter to `paragraph`, you can select a paragraph. Similarly, by setting this parameter to `sentence`, you can select a sentence.
