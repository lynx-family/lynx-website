# SetCModule

<APISummary query="lynx-native-api/lynx-extension-module/set-c-module" />

The `SetCModule` method is responsible for initializing the `LynxExtensionModule` by associating it with its underlying C-API counterpart, `lynx_extension_module_t`. This is a crucial setup step that must be performed to enable the C++ wrapper's functionality.

Calling this method also triggers `BindFunction()`, which connects the C++ virtual methods (like `OnLynxViewCreate`, `OnRuntimeInit`, etc.) to the C-API's callback mechanism.

## Method Signature

```cpp
void SetCModule(lynx_extension_module_t* c_module);
```

## Parameters

| Name       | Type                       | Description                                                | Required |
| ---------- | -------------------------- | ---------------------------------------------------------- | -------- |
| `c_module` | `lynx_extension_module_t*` | A pointer to the C-API `lynx_extension_module_t` instance. | Yes      |

## Usage

This method is typically called by the Lynx framework itself when an extension module is loaded and initialized. You would not normally call this method directly. It is part of the internal binding process that allows your custom C++ `LynxExtensionModule` subclass to receive lifecycle events from the core Lynx engine.
