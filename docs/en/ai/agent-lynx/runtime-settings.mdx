# Runtime Settings

[Connect an app](connections.mdx), then select its client ID.

List the supported global switch keys before reading or changing one:

```bash
agent-lynx global-switch list --client <clientId>
agent-lynx global-switch get --client <clientId> --key enable_debug_mode
agent-lynx global-switch set --client <clientId> --key enable_debug_mode --status on
```

Switches control debugging, DOM/CSS/Page domains, runtime settings, and screenshot behavior. Use `global-switch get --help` for the accepted keys. Follow any app-restart instruction after changing a switch.
