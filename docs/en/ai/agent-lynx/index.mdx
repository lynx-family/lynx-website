# agent-lynx

[agent-lynx](https://github.com/lynx-community/skills/tree/main/packages/agent-lynx) is a toolkit that connects AI agents and automation to Lynx applications. It combines a CLI, a typed Connector API, composable CLI APIs, and bundled skills. Agents can inspect and operate a running page, diagnose performance and memory issues, record interactions, and use runtime feedback to verify code changes.

## Get Started

Follow [Getting Started](getting-started.mdx) to install agent-lynx, give your agent the bundled instructions, and inspect your first page. For scripts and integrations, use the [programmatic APIs](programmatic-api.mdx).

## Skills and MCP Integration

The bundled skills provide instructions for using agent-lynx; the CLI and APIs execute the operations. Read them with `agent-lynx skills list` and `agent-lynx skills get lynx-devtool`. [Agent Skills](https://github.com/lynx-community/skills) also provide Lynx development knowledge, and [AGENTS.md](../agentsmd.mdx) gives agents project-specific context.

If you previously used `lynx-devtool` or skill-local trace scripts, use `agent-lynx` as the CLI entry point and read its current DevTool instructions. The [performance tracing workflow](tracing.mdx) replaces the separate recorder-script entry point.

[Lynx DevTool MCP](../lynx-devtool-mcp.mdx) provides runtime debugging through MCP tools. Choose the entry point that matches your agent integration. [Lynx Docs MCP](../lynx-docs-mcp.mdx) provides documentation access alongside either integration.
