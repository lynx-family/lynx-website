# agent-lynx

[agent-lynx](https://github.com/lynx-community/skills/tree/main/packages/agent-lynx) — **Lynx for your agent**: the knowledge and tools to build, debug, and verify Lynx apps.

It combines a CLI, a typed Connector API, composable CLI APIs, and bundled skills. Agents can inspect and operate a running page, diagnose performance and memory issues, record page runtime state for replay, and use runtime feedback to verify code changes.

## How It Connects to Your App

The agent issues CLI commands on your computer. A shared local daemon keeps the connection to the Lynx app, routes commands to the selected page, and returns runtime feedback. The app exposes a client; its pages expose sessions.

## Skills and Project Context

The bundled skills provide instructions for using agent-lynx; the CLI and APIs execute the operations. Discover them with `agent-lynx skills list`, then load the relevant instructions with `agent-lynx skills get <name>`. [Agent Skills](https://github.com/lynx-community/skills) also provide Lynx development knowledge, and [AGENTS.md](../agentsmd.mdx) gives agents project-specific context.

If you previously used `lynx-devtool` or skill-local trace scripts, use `agent-lynx` as the CLI entry point and read its current DevTool instructions. The [performance tracing workflow](tracing.mdx) replaces the separate recorder-script entry point.
