# CLI Reference

This section documents the public functionality in `agent-lynx@0.14.19`. Start with [Getting Started](getting-started.mdx) for installation and device setup, or browse the [function guides](index.mdx#explore-by-function). The [programmatic APIs](programmatic-api.mdx) have their own reference. Use `agent-lynx <command> --help` for the complete options supported by your installed version.

## Connection Options

| Operation              | Options and behavior                                                                                                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Select an app and page | Pass the returned `--client <clientId>` and `--session <sessionId>` to commands that declare them. Discover IDs again after app restarts or page navigation.                                                                                           |
| Wait for an app        | `wait-for-client --client-name <name> --timeout 30` waits for an app connection. Timeout and polling intervals use **seconds**; page-level `wait` uses milliseconds.                                                                                   |
| Open a page            | `open <bundle-url> --client <clientId>` uses a URL reachable by the app. Run the development server separately, then discover sessions and refresh the snapshot after navigation.                                                                      |
| Manage the daemon      | `daemon status` reads version and protocol information without starting the daemon. `daemon start` and `daemon stop` control its lifecycle. These commands accept `--port`; the default is `21783`.                                                    |
| Use direct transports  | Stop the daemon before using `--no-daemon` to connect directly to the same target. Direct mode supports Android, iOS, Desktop, and HDT. Snapshot refs and their actions, `wait`, `screenshot`, and ReactLynx commands require the default daemon mode. |

## Output, Help, and Environment

Use `--client` and `--session` on commands that declare them to select the target explicitly. Use `--json` where supported to request structured output. The global JSON preference is forwarded only to commands with a JSON mode.

| Environment variable                 | Purpose                                                                            |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| `AGENT_LYNX_FORCE_JSON`              | Set to `1` or `true` to enable supported JSON output modes.                        |
| `AGENT_LYNX_DISABLE_UPDATE_NOTICE`   | Set to `1` to disable npm update notices.                                          |
| `AGENT_LYNX_INVOKED_AS`              | Set the user-facing invocation name in a process host.                             |
| `AGENT_LYNX_CLI_PLACEHOLDER`         | Fallback invocation name for help and recovery hints.                              |
| `ADB_SERVER_HOST`, `ADB_SERVER_PORT` | Configure the direct-mode Android ADB server; defaults are `127.0.0.1` and `5037`. |
| `DEBUG`                              | Enable diagnostic logging namespaces on stderr.                                    |
