# lynx-trace-record

For new trace recording workflows, use [Agent Lynx](../agent-lynx.mdx#record-and-analyze-a-performance-trace). It provides trace capture, download, event summaries, and SQL queries through the same CLI used for page debugging.

## Record with Agent Lynx

```bash
npx --yes agent-lynx skills get lynx-devtool
npx --yes agent-lynx trace start --help
```

Follow the guide to select a client, start recording before opening the page, stop recording, and download the returned stream as a `.pftrace` file.

If your existing `lynx-trace-record` skill invokes a skill-local recorder script, switch to `agent-lynx trace start`, `trace end`, and `trace read-data` using the [Agent Lynx workflow](../agent-lynx.mdx#record-and-analyze-a-performance-trace).
