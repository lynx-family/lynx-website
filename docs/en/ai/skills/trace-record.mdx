# lynx-trace-record

For new trace recording workflows, use [agent-lynx](../agent-lynx/tracing.mdx). It provides trace capture, download, event summaries, and SQL queries through the same CLI used for page debugging.

## Record with agent-lynx

```bash
npx --yes agent-lynx skills get lynx-trace-record
npx --yes agent-lynx trace start --help
```

Follow the guide to select a client, start recording before opening the page, stop recording, and download the returned stream as a `.pftrace` file.

If your existing `lynx-trace-record` skill invokes a skill-local recorder script, switch to `agent-lynx trace start`, `trace end`, and `trace read-data` using the [agent-lynx workflow](../agent-lynx/tracing.mdx).
