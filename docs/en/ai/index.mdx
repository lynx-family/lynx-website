# Lynx for AI

Give your coding agent Lynx project context, development knowledge, and feedback from a running app. Use the following tools together:

| What your agent needs                                          | Start here                                                       |
| -------------------------------------------------------------- | ---------------------------------------------------------------- |
| Inspect a running page, reproduce an issue, or verify a change | [agent-lynx](agent-lynx.mdx)                                     |
| Project commands and conventions                               | [AGENTS.md for Lynx](agentsmd.mdx)                               |
| Lynx development patterns and best practices                   | [Agent Skills](https://github.com/lynx-community/skills)         |
| Current guides and API references                              | [Lynx Docs MCP](lynx-docs-mcp.mdx) or [llms.txt](#using-llmstxt) |

## Debug and Verify with agent-lynx

[agent-lynx](agent-lynx.mdx) connects coding agents to running Lynx apps. It provides page snapshots, element interactions, screenshots, console and source inspection, ReactLynx component inspection, and performance tracing through a CLI.

```bash
npx --yes agent-lynx --help
npx --yes agent-lynx skills get lynx-devtool
npx --yes agent-lynx list-clients
```

Follow the [agent-lynx guide](agent-lynx.mdx) to connect an app and complete your first debugging workflow.

## Set Up Your Project with `AGENTS.md`

The [`AGENTS.md`](https://agents.md) file is similar to `README.md`, but written for coding agents. It gives agents the project-specific context they need to work effectively in your Lynx codebase, with zero dependencies and immediate value.

Learn how to add a suitable `AGENTS.md` for your Lynx project in [AGENTS.md for Lynx](agentsmd.mdx).

## Add Domain Expertise with Agent Skills

[Agent Skills](https://agentskills.io/home) are reusable rule sets that give coding agents domain-specific knowledge about Lynx's dual-thread architecture, common patterns, and debugging techniques. Install the community collection with:

```bash
npx skills add lynx-community/skills
```

Read more in [Agent Skills for Lynx](https://github.com/lynx-community/skills).

## Read Documentation with MCP

[Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) is a standard for connecting coding agents to external tools.

[**Lynx Docs MCP**](lynx-docs-mcp.mdx) lets agents fetch guides and API references directly from the Lynx documentation site. Use it alongside agent-lynx when the agent needs both documentation and runtime feedback.

For existing integrations or clients that require MCP tools for runtime debugging, see [Lynx DevTool MCP](lynx-devtool-mcp.mdx).

## Using `llms.txt`

The Lynx website also supports the [llms.txt](https://llmstxt.org/) standard, which is useful for feeding Lynx documentation into any LLM with web browsing. For every page, you can get the original Markdown by replacing the `.html` extension with `.md`. For example:

- [https://lynxjs.org/llms.txt](https://lynxjs.org/llms.txt)
- [https://lynxjs.org/react/introduction.md](https://lynxjs.org/react/introduction.md)

## Generative UI

Beyond AI helping developers write Lynx code, Lynx also supports AI Agents generating UI at runtime through developer-controlled components. ReactLynx currently provides two integration paths:

- [A2UI](/react/genui/a2ui) renders declarative messages from Google's open Agent-to-UI protocol. Read [Generative UI on Lynx with A2UI](/blog/lynx-a2ui) for the release details.
- [OpenUI](/react/genui/openui) renders compact, streaming OpenUI Lang as native interfaces, with reactive state, tool calls, and an extensible component library.
