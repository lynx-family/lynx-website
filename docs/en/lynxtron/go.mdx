# Lynxtron Go

Lynxtron Go is the official fiddle and playground for Lynxtron. It lets you edit, run, and share small experiments without first creating a full project.

- [Download for macOS (Apple silicon)](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/lynxtron-go-darwin-arm64.dmg)
- [Download for Windows (x64)](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/LynxtronGo-win-x64-Setup.exe)
- [View all releases](https://github.com/lynx-community/lynxtron-examples/releases/latest)

The main workspace brings the application files, package modules, and process Console into one window.

![The Lynxtron Go workspace with application editors, modules, and Console](/assets/lynxtron/go/editor.jpg)

## Start From a Template or Showcase

Click the new-fiddle button in the upper-left corner. Choose **Blank** for an empty application boundary, choose **Hello Lynxtron** for a minimal runnable application, or select **Start from a showcase** to open the gallery.

![Choose a Blank or Hello Lynxtron fiddle, or continue to the showcase gallery](/assets/lynxtron/go/new-fiddle.jpg)

In the gallery, use **Open** to load a showcase into the editor, **Run** to launch it directly, or **IDE** to continue in your local editor. The **Electron Fiddles** collection tracks Lynxtron ports of Electron's `docs/fiddles` examples in their upstream categories and marks each one as working, partial, or not applicable.

![Browse runnable Lynxtron showcases in the built-in gallery](/assets/lynxtron/go/showcase-gallery.jpg)

## Edit the Complete Application Boundary

After opening a fiddle, select files from the **Editors** sidebar. Edit the Node.js main process in `main.js`, the Lynx UI in `renderer.js`, APIs exposed to the UI in `preload.js`, styles in `styles.css`, and dependencies in `package.json`. The split editor keeps these layers visible together, while the **Modules** panel shows the packages available to the fiddle.

## Run and Inspect

Click **Run** in the toolbar to start the current fiddle in a fresh Lynxtron process. The button changes to **Stop**, and process output appears in the Console at the bottom of Lynxtron Go. Stop the process, edit the files, and click **Run** again to repeat the cycle.

![A counter fiddle running in its own Lynxtron window](/assets/lynxtron/go/run-result.jpg)

## Use Packages and Continue in Your IDE

Search for a package in the **Modules** panel to add it to the fiddle. Use **File > Save** to keep the fiddle locally, **File > Open Folder in IDE** to continue in your preferred editor, or the Gist field in the toolbar to load and publish a GitHub Gist. Lynxtron Go is intended for focused experiments and prototypes; when an idea grows into an application, continue with [Lynxtron Quick Start](/lynxtron/introduction) to create a full project.

## Open Documentation Examples

On a runnable example in the Lynxtron documentation, open the launch menu and choose **Open in Lynxtron Go**. The action sends the example bundle to the desktop app; if Lynxtron Go is not installed, it offers the appropriate download after the launch attempt.
