# Lynxtron Go

Lynxtron Go is the official fiddle and playground for Lynxtron. It lets you edit, run, and share small experiments without first creating a full project.

- [Download for macOS (Apple silicon)](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/lynxtron-go-darwin-arm64.dmg)
- [Download for Windows (x64)](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/LynxtronGo-win-x64-Setup.exe)
- [View all releases](https://github.com/lynx-community/lynxtron-examples/releases/latest)

## Start From a Template or Showcase

Create a blank fiddle, begin with the Hello Lynxtron template, or open a curated showcase from the built-in gallery. The gallery also includes Lynxtron ports of Electron Fiddle examples, organized by desktop capability so you can see what is available and inspect how it is implemented.

## Edit the Complete Application Boundary

Work with the Node.js main process, preload code, Lynx UI, styles, and package metadata in one place. Lynxtron Go keeps these files visible together so you can understand where desktop capabilities and UI logic meet.

## Run and Inspect

Run the current fiddle in a fresh Lynxtron process and inspect its output in the built-in console. You can stop it, change the code, and run it again without setting up a separate project.

## Use Packages and Continue in Your IDE

Add npm packages while experimenting, save a fiddle locally, open its folder in your preferred IDE, or load and publish a GitHub Gist. Lynxtron Go is intended for focused experiments and prototypes; when an idea grows into an application, continue with [Lynxtron Quick Start](/lynxtron/introduction) to create a full project.

## Open Documentation Examples

Runnable examples across the Lynxtron documentation include an **Open in Lynxtron Go** action. If Lynxtron Go is not installed, the same action offers the appropriate download after the launch attempt.
