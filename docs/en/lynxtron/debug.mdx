# Debug Lynxtron

Lynxtron uses a DevTool-enabled runtime during local development and a release runtime when packaging by default.

## Debug During Development

Start the generated project in development mode:

<PackageManagerTabs command="run dev" />

When the Lynxtron CLI runs locally, it uses the DevTool-enabled runtime by default.

### Debug the Main Process

The generated development command starts the Node.js inspector on `localhost:9222`.

1. Open `chrome://inspect` in Chrome.
2. Select **Configure...** and make sure `localhost:9222` is in the target discovery list.
3. Find the application's `main.js` under **Remote Target**, then select **inspect**.

### Debug the Lynx UI

Download and open [Lynx DevTool](/guide/devtool) while `npm run dev` is running. Select the Lynxtron application to inspect its elements, console output, and source code.

## Debug a Packaged Application

`electron-builder` uses the release runtime by default. If you specifically need a DevTool-enabled installer for local debugging, add this top-level option:

```yaml title="electron-builder.yml"
lynxtron:
  runtimeVariant: devtool
```

Then package the application:

<PackageManagerTabs command="run pack" />

Open the packaged application and connect with [Lynx DevTool](/guide/devtool) in the same way as during development.

Remove `runtimeVariant: devtool` before distributing the application so subsequent packages use the release runtime.
