### handle()

```ts
handle(method: string, handler: LynxBridgeHandler): void
```

Register a handler for an invoke method. The handler will be called when the
Lynx side calls `bridge.call(method, args)`.

The return value of the handler will be sent back to the Lynx side via
`event.sendReply()`.
