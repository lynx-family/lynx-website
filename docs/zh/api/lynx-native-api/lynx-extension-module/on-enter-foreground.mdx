# OnEnterForeground

<APISummary query="lynx-native-api/lynx-extension-module/on-enter-foreground" />

`OnEnterForeground` 是 `LynxExtensionModule` 类中的一个虚拟生命周期方法。当宿主应用程序从后台转换到前台时，Lynx 框架会调用此方法。

该回调总是在 **UI 线程**上调用。它对于恢复活动、重新启动动画或刷新在应用程序处于后台时可能已暂停或过时的数据非常有用。

## 方法签名

```cpp
virtual void OnEnterForeground();
```

## 使用方法

在您的 `LynxExtensionModule` 子类中重写此方法以处理应用程序前台化事件。例如，您可以恢复视频播放、重新启动 WebSocket 连接或触发数据刷新。

## 代码示例

```cpp
#include "lynx_extension_module.h"

class MyMediaModule : public lynx::pub::LynxExtensionModule {
public:
    void OnEnterForeground() override {
        // 应用程序已进入前台。
        printf("MyMediaModule: 正在恢复活动。\\n");

        // 示例：向 BTS 线程发布一个任务以恢复视频播放器。
        PostTaskToRuntime([]() {
            // videoPlayer->resume();
        });
    }

    void OnEnterBackground() override {
        // 应用程序已进入后台。
        printf("MyMediaModule: 正在暂停活动。\\n");

        // 示例：发布一个任务以暂停视频播放器。
        PostTaskToRuntime([]() {
            // videoPlayer->pause();
        });
    }

    // ... 其他生命周期方法
};
```
