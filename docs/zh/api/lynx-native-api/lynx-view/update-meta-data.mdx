# updateMetaData

<APISummary />

使用 [LynxUpdateMeta](/api/lynx-native-api/lynx-update-meta) 更新 `LynxView`，是客户端更新模板数据的主入口。

本页统一维护各平台更新方法的完整签名、参数、类型和版本说明。

## 平台对应关系

原生平台通过 [LynxUpdateMeta](/api/lynx-native-api/lynx-update-meta) 对象传递模板数据和 globalProps。在 Web 平台上，[`<lynx-view>`](/api/lynx-native-api/lynx-view/lynx-view) 没有元数据结构，其方法直接接收数据。

| 平台          | 更新方法                             | 输入                                                         |
| :------------ | :----------------------------------- | :----------------------------------------------------------- |
| Android       | `updateMetaData`                     | `LynxUpdateMeta`                                             |
| iOS           | `updateMetaData:`                    | `LynxUpdateMeta`                                             |
| Desktop (C++) | `UpdateData`                         | `std::shared_ptr<lynx::pub::LynxUpdateMeta>`                 |
| Web           | `updateData` 和 `updateGlobalProps` | [`Cloneable`](#cloneable) 类型的模板数据或 globalProps |

## 语法

### Android

```java
public void updateMetaData(LynxUpdateMeta meta);
```

#### 参数说明

- `meta`: Lynx 模板更新元数据，开发者通过该数据结构指定更新模板的可选数据内容。

### iOS

```objc
- (void)updateMetaData:(nonnull LynxUpdateMeta *)meta;
```

#### 参数说明

- `meta`: Lynx 模板更新元数据，开发者通过该数据结构指定更新模板的可选数据内容。

### Web

:::info

以下签名适用于 `@lynx-js/web-core` 0.18.0 及以上版本。在更早的版本中，`updateData` 的第二个参数为必填的 `updateDataType: UpdateDataType`；从 0.18.0 起，该参数改为可选的 `processorName?: string`。参见 [0.18.0 更新日志](https://github.com/lynx-family/lynx-stack/blob/main/packages/web-platform/web-core/CHANGELOG.md#0180)。

:::

```ts
updateData(
  data: Cloneable,
  processorName?: string,
  callback?: () => void,
): void;
updateGlobalProps(data: Cloneable): void;
```

#### 参数说明

- `data`: 要更新的数据，应与 `structuredClone` 兼容。对于 `updateData`，它是模板数据；对于 `updateGlobalProps`，它是 globalProps。
- `processorName`: 可选。在更新前处理 `data` 的 `dataProcessor` 名称。省略时使用默认的 `dataProcessor`。参见[使用宿主平台数据](/guide/use-data-from-host-platform)。
- `callback`: 可选。更新完成后调用。

#### Cloneable

`<lynx-view>` 方法（包括 [`sendGlobalEvent`](/api/lynx-native-api/lynx-view/send-global-event)）接收的数据使用 `Cloneable` 类型声明：

```ts
export type Cloneable<T = string | number | null | boolean | undefined> =
  | T
  | Record<string, T>
  | T[]
  | Array<Record<string, Cloneable>>;
```

### Desktop (C++)

```cpp
void UpdateData(std::shared_ptr<lynx::pub::LynxUpdateMeta> update_meta);
```

#### 参数说明

- `update_meta`: 用于提供模板数据和全局属性的更新元数据。
