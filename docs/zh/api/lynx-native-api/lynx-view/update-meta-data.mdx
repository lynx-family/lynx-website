# updateMetaData

<APISummary />

使用 [LynxUpdateMeta](/api/lynx-native-api/lynx-update-meta) 更新 `LynxView`，是客户端更新模板数据的主入口。

## 语法

### Android

```java
public void updateMetaData(LynxUpdateMeta meta);
```

#### 参数说明

- `meta`: Lynx 模板更新元数据，开发者通过该数据结构指定更新模板的可选数据内容。

### iOS

```objc
- (void)updateMetaData:(nonnull LynxUpdateMeta *)meta;
```

#### 参数说明

- `meta`: Lynx 模板更新元数据，开发者通过该数据结构指定更新模板的可选数据内容。

### Web

:::info

以下签名适用于 `@lynx-js/web-core` 0.18.0 及以上版本。在更早的版本中，`updateData` 的第二个参数为必填的 `updateDataType: UpdateDataType`；从 0.18.0 起，该参数改为可选的 `processorName?: string`。参见 [0.18.0 更新日志](https://github.com/lynx-family/lynx-stack/blob/main/packages/web-platform/web-core/CHANGELOG.md#0180)。

:::

```ts
export type Cloneable<T = string | number | null | boolean | undefined> =
  | T
  | Record<string, T>
  | T[]
  | Array<Record<string, Cloneable>>;

updateData(
  data: Cloneable,
  processorName?: string,
  callback?: () => void,
): void;
updateGlobalProps(data: Cloneable): void;
```

#### 参数说明

- `data`: 要更新的数据，应与 `structuredClone` 兼容。
### Desktop (C++)

```cpp
void UpdateData(std::shared_ptr<lynx::pub::LynxUpdateMeta> update_meta);
```

#### 参数说明

- `update_meta`: 用于提供模板数据和全局属性的更新元数据。
