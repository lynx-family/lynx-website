# `<textarea>`

<APISummary />

`<textarea>` 用于创建交互式输入控件，允许用户输入和编辑多行文本。

:::info

此功能需要客户端添加额外依赖才能被使用，集成方式请请参考 [More Elements](/guide/start/integrate-with-existing-apps).

:::
