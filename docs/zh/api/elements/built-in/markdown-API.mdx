## 属性

前端可以在元件上设置相应属性来定义组件的运行时行为，使用方法如下。

```tsx
<markdown content={content} />
```

### `content`

```ts
/**
 * markdown source content.
 */
content: string;
```

markdown 内容

### `content-id`

```ts
/**
 * mark the content when the event or UI method is triggered.
 */
'content-id'?: string;
```

作为`content`的唯一标识符，用于在事件中消费。

### `markdown-style`

```ts
/**
 * set the style of markdown.
 * @defaultValue {}
 */
'markdown-style'?: object
```

markdown 的样式，具体格式请参考[样式表](#样式表)

### `animation-type`

```ts
/**
 * which animation to use.
 * none: no animation
 * typewriter: typewriter animation
 * @defaultValue 'none'
 */
'animation-type'?: 'none' | 'typewriter'
```

markdown 的动画样式，可以选择指定开启打字机效果

### `animation-velocity`

```ts
/**
 * velocity of animation.
 * when animation-type is typewriter, it's the number of characters typed per second.
 * @defaultValue 1
 */
'animation-velocity'?:number;
```

markdown 打字机效果的速度

### `text-maxline`

```ts
/**
 * maximum number of text lines.
 * a table row is counted as a line
 */
'text-maxline'?: number;
```

markdown 文本最大行数

### `overflow`

```ts
overflow?: 'ellipsis' | 'clip';
```

控制文本溢出时显示省略号还是直接裁剪，默认为 `ellipsis`。

### `initial-animation-step`

```ts
/**
 * animation will start at the given step.
 * @defaultValue 0
 */
'initial-animation-step'?: number
```

指定 markdown 动画开始的位置

### `content-complete`

```ts
/**
 * whether to hide the typewriter cursor.
 * true: typewriter cursor will be hidden and drawEnd event will be triggered after the animation is complete.
 * false: typewriter cursor will be shown and drawEnd event will not be triggered.
 * @defaultValue true
 */
'content-complete'?: boolean;
```

标明当前`content`是否完整，如果为`true`，则会在动画结束后隐藏光标，否则会一直显示光标

### `typewriter-dynamic-height`

```ts
/**
 * whether markdown height is equal to the content height typed by typewriter
 * @defaultValue false
 */
'typewriter-dynamic-height'?: boolean
```

配置打字机效果是否动态改变元素高度

### `text-selection`

```ts
/**
 * whether markdown content is selectable.
 * @defaultValue false
 */
'text-selection'?: boolean
```

配置 markdown 内容是否可选择

### `text-mark-attachments`

用于复杂高亮：多段重叠、跨行、与下划线/描边混合的场景。

```ts
/**
 * 定义文本高亮附件，用于在指定字符范围内添加高亮或下划线。
 * 附件按行绘制，并在跨行时保持渐变连续。
 * @defaultValue []
 */
'text-mark-attachments'?: MarkAttachment[];

interface LineStyle {
  lineType: 'none' | 'solid' | 'dashed';
  color: string; // 16进制颜色或者gradient
  width: number; // 单位为px
  elementSize?: number; // 虚线元素长度
  emptySize?: number; // 虚线间隔长度
}

interface MarkStyle {
  radius?: number; // 圆角半径，单位为px
  left?: number; // 单位为px
  right?: number; // 单位为px
  top?: number; // 单位为px
  bottom?: number; // 单位为px
  color?: string; // 矩形填充颜色或者gradient
  borderLeft?: LineStyle;
  borderTop?: LineStyle;
  borderRight?: LineStyle;
  borderBottom?: LineStyle;
}

interface MarkAttachment {
  startIndex: number;
  endIndex: number; // 不包含该位置（exclusive）
  indexType: 'char' | 'source';
  clickable?: boolean;
  id?: string;
  layer?: 'background' | 'foreground';
  style: MarkStyle;
}
```

### `content-range`

```ts
/**
 * the range of content to be parsed.
 * @defaultValue [0, int32_max]
 */
'content-range'?: number[];
```

配置 Markdown 源文本的解析范围。

### `markdown-effect`

```ts
/**
 * additional effects
 * @defaultValue {}
 */
'markdown-effect'?: object
```

配置额外渲染效果。渐隐遮罩使用 `{ type: 'text-mask', color, rangeStart, rangeEnd }`，见[文本渐隐效果](#文本渐隐效果)。

### `typewriter-height-transition-duration`

```ts
/**
 * transition duration when height extended by typewriter animation.
 * @defaultValue 0
 */
'typewriter-height-transition-duration'?: number
```

配置打字机高度变化时的过渡时长，单位为秒，默认值为 `0`。配合 `typewriter-dynamic-height` 使用。

### `enable-gif`

```ts
/**
 * whether to enable gif animation.
 * @defaultValue false
 */
'enable-gif'?: boolean
```

配置iOS是否开启gif动画，安卓默认支持gif动画。

## 方法

前端可以通过 [SelectorQuery](/zh/api/lynx-api/nodes-ref/nodes-ref-invoke.md) API 执行元件的方法，使用方法如下：

```ts title=index.js
lynx
  .createSelectorQuery() // 创建 SelectorQuery
  .select('#markdown') // 指定目标节点的选择器
  .invoke({
    // 指定对目标节点的操作
    method: 'pauseAnimation',
    success: function (res) {
      console.log(res);
    },
    fail: function (res) {
      console.log(res.code, res.data);
    },
  })
  .exec(); // 执行查询
```

      top: number;
      right: number;
      bottom: number;
      width: number;
      height: number;
    }[];

     */

      y: number;

}
