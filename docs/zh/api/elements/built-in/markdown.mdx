# `<markdown>`

<APISummary />

`<markdown>` 在 Lynx 中渲染 Markdown 内容，支持标题、段落、引用、列表、代码、链接、图片和表格，并提供内嵌 View、打字机动画与文本选择能力。

宿主需要集成并注册该原生元件。使用支持 `<markdown>` 的 Lynx Explorer 运行示例；各属性和方法的平台支持情况见[兼容性](#兼容性)。

### 修改样式

`<markdown>` 内部的元素并不是一个 Lynx 元素，因此无法通过 CSS 来赋予样式，但是我们可以通过 `markdown-style` 属性来修改内部元素的样式。

在上面的代码中我们通过 `markdown-style` 传入了一个 object，它表示将所有的 `normalText` 即普通文本的字号设置为 25px 以及将 `inlineCode` 即行内代码的字号设置成了 20px、颜色设置成了红色。

`markdown-style` 就是这样的一系列 tag 到样式配置项的映射，通过它能修改某一个语法的样式。支持的 tag 及其配置项见[样式表](#样式表)。

### 文本截断

`markdown` 自带超出截断功能，是否添加省略号可以通过 `overflow` 属性来设置，默认值为 `ellipsis` 代表会添加省略号，设置值为 `clip` 代表不会添加省略号，表格不支持添加省略号。

通过 `text-maxline` 属性可以控制文本的最大行数，通过 `height` 样式可以控制文本的最大高度，二者同时存在时会同时生效。

<Go

#### 实现菜单

`getTextBoundingRect` 返回页面坐标。将它用于容器内绝对定位的菜单时，需要减去容器的 `boundingClientRect` 坐标。该示例只展示菜单；后续示例再添加按钮行为。

在选中区域有变化时，会触发 `selectionchange` 事件，事件的参数中会包含选中的起始位置和结束位置，如果当前选中区域为空，则起始位置和结束位置都为-1，我们可以通过判断起始位置和结束位置是否为-1来实现菜单的显示和隐藏。

在显示了菜单后，需要根据选中的区域来调整菜单的位置，这里我们可以通过 `getTextBoundingRect` 方法来获取选中区域的位置。这个方法需要传入选中区域的起始位置和结束位置，返回值是一个 `TextBoundingRect` 对象，对象中包含了选中区域的总的 boundingRect 以及每行单独的 boundingRect。

```ts
interface Rect {
  left: number;
  right: number;
  top: number;
  bottom: number;
  width: number;
  height: number;
}

interface TextBoundingRect {
  boundingRect: Rect;
  boxes: Rect[];
}
```

这里使用总 boundingRect 将菜单水平居中定位在选中区域上方。示例代码如下：

#### 选择段落或句子

`setTextSelection` 接收相对于 `<markdown>` 的坐标。用文本边界框的中心定位段落时，先减去 `<markdown>` 自身的页面坐标，再传入相同的起点和终点。

默认情况下 `markdown` 在长按之后只会选中当前触摸位置的字符，如果想要在长按之后选中一个段落，需要在 `selectionchange` 事件中调整选中区域。

`setTextSelection` 方法还可以传入一个 `selectionTextType` 参数，当 start 和 end 位置相同时，这个参数才会生效，它用来指定选中的文本类型，值可以是 `char`，`word`，`sentence` 以及 `paragraph`。

将这个参数设置为 `paragraph` 即可选中一个段落，同理，将这个参数设置为 `sentence` 即可选中一个句子。
