# `<scroll-view>`

<APISummary />

基础滚动组件，支持横向和竖向滚动。当其内容区域比其本身可视区域更大时，允许用户滚动以展示更多内容。

## 使用指南

### 横向与纵向滚动

`<scroll-view>` 每次沿一个方向滚动，由 `scroll-orientation` 配置，默认值为 `vertical`。需要为滚动方向设置有界的可视尺寸，使内容可以超出可视区域。

`<scroll-view>` 对直接子节点使用 [linear](/guide/ui/layout/linear-layout.mdx) 布局，方向由 `scroll-orientation` 决定。若滚动内容需要使用 Flex 布局或其他布局方式，可将内容放入一个子 `<view>` 中。

### 吸顶能力

为 `<scroll-view>` 的直接子节点设置 `sticky`，可在内容滚动经过指定位置后，将该节点保持在配置的边缘偏移处。例如，纵向滚动时可以配合 `top: 0` 实现吸顶。

:::tip
`sticky` 只能设置给 `<scroll-view>` 的直接子节点。<AndroidOnly /> 上需要为 `sticky` 节点添加 `flatten={false}`。

滚动容器以线性方式排列直接子节点，但不限制每个子节点内部的布局。可以通过包装节点实现更复杂的内容布局：

```tsx
<scroll-view scroll-orientation="vertical" style={{ height: '300px' }}>
  <view style={{ display: 'flex', flexDirection: 'row' }}>
    <text>第一项</text>
    <text>第二项</text>
  </view>
</scroll-view>
```

:::

## 性能优化建议

`<scroll-view>` 会创建所有传入的子节点，不会自动虚拟化或复用节点。内容较多时，会增加首屏渲染耗时与内存占用。

对于长列表或持续增长的数据集合，优先使用 [`<list>`](./list.mdx)。曝光事件可用于延迟执行高开销操作，但不会让 `<scroll-view>` 自动变成虚拟列表，也不会自动移除屏幕外的节点。
