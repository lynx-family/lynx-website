## 属性

### `enable-scrollbar`

 <ClayOnly /> <WebOnly />

```tsx
// @默认值: false
'enable-scrollbar'?: boolean;
```

当内容发生溢出时启用滚动条。该名称是 Clay 上的推荐名称；Web Lynx 的 `<scroll-view>` 也接受该名称。

在 Clay 上，启用滚动条不等于让滚动条持续显示：[`scroll-bar-auto-hide`](#scroll-bar-auto-hide) 默认为 `true`，滚动条会在交互时出现，并在 [`scroll-bar-auto-hide-delay`](#scroll-bar-auto-hide-delay) 指定的延迟后隐藏。设置 `scroll-bar-auto-hide={false}` 才会在内容溢出时持续显示滚动条。

 <AndroidOnly /> <IOSOnly /> <ClayOnly /> <HarmonyOnly /> <VersionBadge>2.17</VersionBadge>

### `lower-threshold`

### `scroll-bar-enable`

 <AndroidOnly /> <IOSOnly /> <ClayOnly /> <HarmonyOnly /> <WebOnly /> <VersionBadge>1.4</VersionBadge>

```tsx
// @默认值: false
'scroll-bar-enable'?: boolean;
```

当内容发生溢出时启用滚动条。Android 仅支持纵向滚动条。在 Clay 上，该名称是已弃用的别名，请改用 [`enable-scrollbar`](#enable-scrollbar)。Web Lynx 的 `<scroll-view>` 同时接受这两个名称。

### `scroll-bar-auto-hide`

 <ClayOnly />

```tsx
// @默认值: true
'scroll-bar-auto-hide'?: boolean;
```

控制已启用的滚动条是否在滚动或指针交互停止后隐藏。设置为 `false` 后，只要内容发生溢出，滚动条就会持续显示。

### `scroll-bar-auto-hide-delay`

 <ClayOnly />

```tsx
// @默认值: 1000
'scroll-bar-auto-hide-delay'?: number;
```

自动隐藏的滚动条开始隐藏前的延迟，单位为毫秒。

## 事件

前端可以绑定相应的事件回调来监听元素的运行时行为，如下所示。

### `bindcontentsizechanged`
 <AndroidOnly /> <IOSOnly /> <HarmonyOnly /> <VersionBadge>1.6</VersionBadge>

```tsx
bindcontentsizechanged = (e: ContentSizeChangedEvent) => {};
```

当滚动视图的内容大小发生变化时，会触发此事件。

### `bindscroll`
 <AndroidOnly /> <IOSOnly /> <ClayOnly /> <HarmonyOnly /> <VersionBadge>1.4</VersionBadge>

```tsx
bindscroll = (e: ScrollEvent) => {};
```

当滚动视图正在滚动时，会触发此事件。

### `bindscrollend`
 <AndroidOnly /> <IOSOnly /> <ClayOnly /> <HarmonyOnly /> <VersionBadge>1.6</VersionBadge>

```tsx
bindscrollend = (e: ScrollEndEvent) => {};
```

当滚动视图的滚动结束时，会触发此事件。

### `bindscrolltolower`
 <AndroidOnly /> <IOSOnly /> <HarmonyOnly /> <VersionBadge>1.4</VersionBadge>

```tsx
bindscrolltolower = (e: ScrollToLowerEvent) => {};
```

当滚动区域的下/右边缘与由 lowerThreshold 定义的可见区域相交时，会触发此事件。

### `bindscrolltoupper`
 <AndroidOnly /> <IOSOnly /> <HarmonyOnly /> <VersionBadge>1.4</VersionBadge>

```tsx
bindscrolltoupper = (e: ScrollToUpperEvent) => {};
```

当滚动区域的上/左边缘与由 upperThreshold 定义的可见区域相交时，会触发此事件。

## 方法

前端可以通过 [SelectorQuery](/api/lynx-api/nodes-ref/nodes-ref-invoke.html) API 调用组件方法。

### `autoScroll`

 <AndroidOnly /> <IOSOnly /> <ClayOnly /> <HarmonyOnly />
```ts

lynx.createSelectorQuery()
     .select('#id')
     .invoke({
      method: 'autoScroll',
      params: {
        /**
         * 每秒滚动的距离，支持正负数。距离单位可以是 "px"、"rpx"、"ppx" 或 null（对于 iOS，该值必须大于 1/屏幕缩放比例 px）。
         * @Android
         * @iOS
         * @Harmony
         * @PC
         */
        rate: number;
        /**
         * 开始/停止自动滚动。
         * @Android
         * @iOS
         * @Harmony
         * @PC
         */
        start: boolean;
      };
      success: function (res) {},
      fail: function (res) {},
    })
    .exec();

```

自动滚动


### `getScrollInfo`

 <AndroidOnly /> <IOSOnly /> <ClayOnly /> <HarmonyOnly />
```ts

lynx.createSelectorQuery()
     .select('#id')
     .invoke({
      method: 'getScrollInfo',
      success: Callback<{
        /**
         * 沿方向的总可滚动范围，单位为 PX
         * @Android
         * @iOS
         * @Harmony
         * @PC
         */
        scrollRange: number;
        /**
         * X 轴上的内容偏移量，单位为 PX
         * @Android
         * @iOS
         * @Harmony
         * @PC
         */
        scrollX: number;
        /**
         * Y 轴上的内容偏移量，单位为 PX
         * @Android
         * @iOS
         * @Harmony
         * @PC
         */
        scrollY: number;
      }>;
      fail: function (res) {},
    })
    .exec();

```

获取滚动信息
