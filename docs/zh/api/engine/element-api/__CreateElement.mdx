# \_\_CreateElement()

```ts
function __CreateElement(
   tag: string,
   comParentUniID: number,
   info?: ElementInfo): ElementRef
```

Creates an Element object.

The return value is a reference-counted Element managed by `base::scoped_refptr<Element>`.
The frontend framework can hold this return value to manage the Element's lifecycle.
The Element will only be destroyed when the frontend framework no longer holds it
and the Element is removed from the tree.

| 范围 | 类型 | 描述 |

| `comParentUniID` | `number` | The Unique Component ID of the ComponentElement that creates this Element, which is a number. |
| `info`? | [`ElementInfo`](/api/engine/element-api/TypeAlias.ElementInfo.mdx) | Additional information required when creating the Element; this parameter can be omitted. |

**返回**
