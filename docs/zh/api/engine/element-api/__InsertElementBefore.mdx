function __InsertElementBefore(
   parent: ElementRef,

Inserts an Element node into the specified parent node, before the reference node.

**参数**

| 范围 | 类型 | 描述 |

| `current` | [`ElementRef`](/api/engine/element-api/Interface.ElementRef.mdx) | The child node to be inserted into the parent node. |
| `marker` | `undefined` \| `null` \| [`ElementRef`](/api/engine/element-api/Interface.ElementRef.mdx) | The reference node before which the child node needs to be inserted. Pass `null` or `undefined` to insert the child node at the end. |

**返回**
