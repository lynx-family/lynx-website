# lynx: unsubscribeSessionStorage() static method

<APISummary />

`lynx.unsubscribeSessionStorage` 方法用于取消通过 [lynx.subscribeSessionStorage](./lynx-subscribe-session-storage.mdx) 在当前 WhiteBoard 中注册的数据变化监听。取消监听不会删除缓存数据。

共享范围、原生配置和生命周期管理详见 [跨 LynxView 共享数据](../../../guide/share-data-across-lynxviews.md)。

## 语法

```ts
lynx.unsubscribeSessionStorage(key, id);
```

### 参数

#### key

缓存数据 key，通过该 key 来获取缓存数据以及监听数据变化。

#### id

监听数据变化的 id，通过 [lynx.subscribeSessionStorage](./lynx-subscribe-session-storage.mdx) 方法返回的 id 来取消监听。

### 返回值

无（`undefined`）。
