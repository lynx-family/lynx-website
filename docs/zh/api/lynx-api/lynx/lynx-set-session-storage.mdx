# lynx: setSessionStorageItem() static method

<APISummary />

`lynx.setSessionStorageItem` 方法用于设置当前 WhiteBoard 中的缓存数据。只有共享该 WhiteBoard 的 LynxView 才能访问相同的数据。可以调用 [lynx.getSessionStorageItem](./lynx-get-session-storage.mdx) 获取数据。

共享范围、原生配置和生命周期管理详见 [跨 LynxView 共享数据](../../../guide/share-data-across-lynxviews.md)。

## 语法

```ts
setSessionStorageItem(key: string, value: object): void;
```

### 参数

#### key

设置缓存数据的 key，后续可通过该 key 来获取缓存数据以及监听数据变化。

#### value

需要存储的数据对象。

### 返回值

无（`undefined`）。
