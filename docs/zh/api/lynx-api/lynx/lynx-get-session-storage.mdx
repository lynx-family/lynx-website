# lynx: getSessionStorageItem() static method

<APISummary />

`lynx.getSessionStorageItem` 方法用于获取当前 WhiteBoard 中的缓存数据。共享该 WhiteBoard 的 LynxView 可以获取相同的数据。可以调用 [lynx.setSessionStorageItem](./lynx-set-session-storage.mdx) 设置数据。

共享范围、原生配置和生命周期管理详见 [跨 LynxView 共享数据](../../../guide/share-data-across-lynxviews.md)。

## 语法

```ts
lynx.getSessionStorageItem(key, (value) => {});
```

### 参数

#### key

缓存数据 key，通过该 key 来获取缓存数据以及监听数据变化。

#### callback

获取缓存数据的回调函数，参数为缓存的数据对象。

### 返回值

无（`undefined`）。
