# lynx: subscribeSessionStorage() static method

<APISummary />

`lynx.subscribeSessionStorage` 方法用于监听当前 WhiteBoard 中缓存数据的变化，包括共享该 WhiteBoard 的其他 LynxView 所做的修改。可以调用 [lynx.setSessionStorageItem](./lynx-set-session-storage.mdx) 设置数据。

共享范围、原生配置和生命周期管理详见 [跨 LynxView 共享数据](../../../guide/share-data-across-lynxviews.md)。

## 语法

```ts
let id = lynx.subscribeSessionStorage(key, (value) => {});
```

### 参数

#### key

缓存数据 key，通过该 key 来获取缓存数据以及监听数据变化。

#### callback

监听缓存数据的回调函数，参数为缓存的数据对象。

### 返回值

`id: number`, 监听数据变化的 id，可通过该 id 来取消监听。
