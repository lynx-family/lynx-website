## Lynx 扩展

### `GlobalProps.disable`

禁用当前 Lynx 目标的 GlobalProps 变更事件。

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_global_props_agent.cc`

###### 参数

无参数。

###### 返回字段

无返回字段。

###### 备注

- 通过 LynxDevToolMediator 分发至 TASM 任务执行器上的 InspectorTasmExecutor。
- 该操作具有幂等性，返回空的 result 对象。
- 禁用事件后，仍可调用 `GlobalProps.get` 和 `GlobalProps.replace`。
- TASM 目标不可用时，返回错误码为 `-32000` 的 CDP 错误。

###### 示例

**禁用 GlobalProps 事件**

请求：

```json
{
  "id": 1,
  "method": "GlobalProps.disable"
}
```

响应：

```json
{
  "id": 1,
  "result": {}
}
```

### `GlobalProps.enable`

启用当前 Lynx 目标的 GlobalProps 变更事件。

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_global_props_agent.cc`

###### 参数

无参数。

###### 返回字段

无返回字段。

###### 事件

- `GlobalProps.changed`：每次权威数据更新时发出，包含后端生成的时间戳和单个 replace 变更项。调用 `GlobalProps.get` 读取当前完整值。

###### 备注

- 通过 LynxDevToolMediator 分发至 TASM 任务执行器上的 InspectorTasmExecutor。
- 该操作具有幂等性，返回空的 result 对象。
- 启用后，调用 `GlobalProps.get` 获取初始值及其时间戳；启用之前发生的更新不会重放。
- TASM 目标不可用时，返回错误码为 `-32000` 的 CDP 错误。

###### 示例

**启用 GlobalProps 事件**

请求：

```json
{
  "id": 1,
  "method": "GlobalProps.enable"
}
```

响应：

```json
{
  "id": 1,
  "result": {}
}
```

### `GlobalProps.get`

返回当前 Lynx 目标的完整 GlobalProps 权威数据对象。

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_global_props_agent.cc`

###### 参数

无参数。

###### 返回字段

| 名称          | 类型     | 说明                                                                                                                                                                                                    |
| ------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `globalProps` | `object` | 从 TemplateAssembler 读取的当前完整 GlobalProps 值。值为空或尚未初始化时，返回空对象。                                                                                                                  |
| `timestamp`   | `number` | 后端为最近一次已应用的 GlobalProps 变更生成的时间戳，在同一目标内单调递增。前端使用它判断 `GlobalProps.changed` 事件与此响应的先后顺序，例如在收到 replace 标记后重新获取数据时。尚未观察到变更时为零。 |

###### 备注

- 通过 LynxDevToolMediator 分发至 TASM 任务执行器上的 InspectorTasmExecutor。
- 响应在离开 TASM 任务执行器之前完成序列化。
- TASM 目标不可用时，返回错误码为 `-32000` 的 CDP 错误。

###### 示例

**获取当前 GlobalProps**

请求：

```json
{
  "id": 1,
  "method": "GlobalProps.get"
}
```

响应：

```json
{
  "id": 1,
  "result": {
    "globalProps": {
      "theme": "dark"
    },
    "timestamp": 1786956000123
  }
}
```

### `GlobalProps.replace`

以原子方式替换当前 Lynx 目标的完整 GlobalProps 权威数据对象。

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_global_props_agent.cc`

###### 参数

| 名称          | 类型     | 必填 | 说明                                                          |
| ------------- | -------- | ---- | ------------------------------------------------------------- |
| `globalProps` | `object` | 是   | 用于替换的完整 GlobalProps 对象。此对象中未包含的键将被移除。 |

###### 返回字段

无返回字段。

###### 事件

- `GlobalProps.changed`：发出单个 replace 变更项。前端必须调用 `GlobalProps.get` 重建完整状态。replace 变更项不携带字段值。

###### 备注

- 通过 LynxDevToolMediator 分发至 TASM 任务执行器上的 InspectorTasmExecutor。
- 值必须是 JSON 对象；数组、标量值和 `null` 均会被拒绝。
- 更新通过 `TemplateAssembler::UpdateGlobalProps` 执行，因此 TASM 缓存、MTS 和 BTS 中的数据映射以及渲染均遵循正常的 GlobalProps 处理流程。
- TASM 目标不可用时，返回错误码为 `-32000` 的 CDP 错误。

###### 示例

**替换 GlobalProps**

请求：

```json
{
  "id": 1,
  "method": "GlobalProps.replace",
  "params": {
    "globalProps": {
      "theme": "dark"
    }
  }
}
```

响应：

```json
{
  "id": 1,
  "result": {}
}
```
