## Lynx 扩展

### `LynxNativeModule.disable`

禁用当前 Lynx 目标的 NativeModule 实时记录事件。

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_lynx_native_module_agent.cc`

###### 参数

无参数。

###### 返回字段

无返回字段。

###### 备注

- 禁用实时事件后，仍会继续记录，并保留在容量有限的历史记录中。
- 该操作具有幂等性，返回空的 result 对象。

###### 示例

**禁用 NativeModule 实时记录事件**

请求：

```json
{
  "id": 1,
  "method": "LynxNativeModule.disable"
}
```

响应：

```json
{
  "id": 1,
  "result": {}
}
```

### `LynxNativeModule.enable`

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_lynx_native_module_agent.cc`

###### 参数

无参数。

###### 返回字段

无返回字段。

###### 事件

- `LynxNativeModule.recordAdded`：捕获 NativeModule 调用、回调或全局事件记录时发出。

###### 备注

- 仍可通过 `LynxNativeModule.getRecords` 获取已有记录。

### `LynxNativeModule.getRecords`

返回当前 Lynx 目标的 NativeModule 历史记录，其容量有限。

- 来源类型：`lynx-extension`
- 源码：`devtool/lynx_devtool/agent/domain_agent/inspector_lynx_native_module_agent.cc`

###### 参数

无参数。

###### 返回字段

| 名称             | 类型     | 说明                                                       |
| ---------------- | -------- | ---------------------------------------------------------- |
| `records`        | `array`  | 按序号顺序排列的已捕获记录，包括调用、回调和全局事件记录。 |
| `latestSequence` | `number` | 最近一条已捕获记录的序号；历史记录为空时为零。             |

###### 备注

- 历史记录最多保留 200 条，序列化后的记录数据最多为 4 MiB。
- 获取记录不会改变实时上报的启用状态。

###### 示例

**读取 NativeModule 历史记录**

请求：

```json
{
  "id": 1,
  "method": "LynxNativeModule.getRecords"
}
```

响应：

```json
{
  "id": 1,
  "result": {
    "records": [],
    "latestSequence": 0
  }
}
```
