## 介绍

在[网格布局](/guide/ui/layout/grid-layout.mdx)中，指定网格项目的列跨度。用于简化开发，W3C 没有这个属性。

## 语法

```css
/* <number> values */
grid-column-span: 1;
grid-column-span: 2;
```

### 取值

- `<number>`

  [`<number>`](/api/css/data-type/number.mdx) 整数数字，表示网格项目在列方向上的跨度。暂不支持负数。

## 与 Web 的区别

- Web 没有这个属性。

## 注意事项

- 当 [`grid-column-start`](./grid-column-start) 和 [`grid-column-end`](./grid-column-end) 指定了两个不同的具体网格线位置时，列跨度由两条网格线之间的距离决定，`grid-column-span` 不再生效。下面的网格项目占 3 列：

  ```css
  grid-column-start: 2;
  grid-column-end: 5;
  grid-column-span: 1;
  ```

- 不要将 `grid-column-span` 与 `grid-column-start` 或 `grid-column-end` 中的 `span <number>` 混用。它们都会指定列跨度，并可能相互覆盖。下面的声明同时指定了 3 列和 1 列这两个冲突的跨度：

  ```css
  grid-column-start: 2;
  grid-column-end: span 3;
  grid-column-span: 1;
  ```
