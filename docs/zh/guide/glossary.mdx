## SDK

Lynx [软件开发工具包 (SDK)](https://en.wikipedia.org/wiki/Software_development_kit) 是一组工具、库和 API，使开发者能够为 Lynx 构建应用程序。它封装了两层：一层是本机层：[引擎](#引擎)，另一层是脚本层（或前端层）：[框架](#框架)。

### 引擎

Lynx SDK 的一部分，负责将 Lynx 页面转换为屏幕上的像素，并提供 API 以形成 [Lynx 平台](#lynx-平台)。

它被写成 C++ 核心，并带有用平台原生语言（例如 iOS 的 Objective-C、Android 的 Java/Kotlin 等）编写的平台特定层，确保高性能和访问底层系统资源，并且需要与主机应用程序一起本地集成和交付。

### 框架

Lynx SDK 的一部分，提供运行时库和高级 UI 编程模型，使 Lynx 应用程序开发人员能够编写应用程序逻辑和 UI 组件。它被写成 JavaScript，并需要与应用程序代码一起在需要时从文件系统或内存中加载。

目前，Lynx SDK 提供了两种框架：[ReactLynx]。

## Lynx 平台

类似于 [Web 平台](https://en.wikipedia.org/wiki/Web_platform)，Lynx 平台是 Lynx 引擎提供给脚本开发者的 API 和功能的集合，例如[元素](#元素)、[事件](#事件)、[样式](#样式)、[脚本运行时环境](#脚本运行时环境)等。

### 模板

模板是 Lynx 引擎编译后加载的代码包，用于为 Lynx 页面（或应用程序）提供动力。

### 脚本运行时环境

脚本运行时环境使用脚本引擎执行脚本。Lynx 支持主线程脚本和后台线程脚本，两者分别在对应的运行时环境中执行。

<span id="背景线程" />

### 后台线程

后台线程是主线程以外的线程，用于执行后台线程脚本。

### 主线程

Lynx 主线程负责处理用户事件和绘制。在默认线程模型中，主线程脚本、布局和绘制在同一个线程上执行，因此长时间运行的主线程脚本会阻塞页面响应。

### JS 线程

这是后台线程的历史名称。由于 Lynx 也能在主线程执行 JavaScript，该名称存在歧义，已不再推荐使用。

### UI 线程

UI 线程是底层操作系统视为主线程的物理线程。Lynx 主线程是否与 UI 线程对应，取决于使用的线程模型。

### Lepus

Lynx 中与主线程脚本执行相关的历史名称，曾用于指代脚本引擎、运行时或线程。描述具体实现时，应明确所指。

### Lepus 虚拟机

Lynx 原有的轻量脚本引擎，支持 JavaScript 的部分能力，与基于 QuickJS 的 PrimJS 引擎不同。

### PrimJS 虚拟机

[PrimJS](https://github.com/lynx-family/primjs) 是专为 Lynx 设计、基于 QuickJS 构建的开源 JavaScript 引擎，旧称 LepusNG。它用于[主线程运行时](/guide/scripting-runtime/main-thread-runtime)，也可以执行后台线程脚本。
