# Lynxtron Go

Lynxtron Go 是 Lynxtron 官方提供的 fiddle 和 playground。无需先创建完整工程，即可编辑、运行和分享小型实验。

- [下载 macOS 版本（Apple 芯片）](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/lynxtron-go-darwin-arm64.dmg)
- [下载 Windows 版本（x64）](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/LynxtronGo-win-x64-Setup.exe)
- [查看全部版本](https://github.com/lynx-community/lynxtron-examples/releases/latest)

## 从模板或示例开始

你可以创建空白 fiddle、从 Hello Lynxtron 模板开始，或者在内置 Gallery 中打开精选示例。Gallery 还收录了移植到 Lynxtron 的 Electron Fiddle 示例，并按照桌面能力分类，便于查看当前支持情况及其实现方式。

## 同时编辑完整的应用边界

在同一个界面中编辑 Node.js 主进程、preload、Lynx UI、样式和包元数据。Lynxtron Go 将这些文件放在一起，帮助你理解桌面能力和 UI 逻辑在哪里衔接。

## 运行和检查

在新的 Lynxtron 进程中运行当前 fiddle，并通过内置 Console 查看输出。无需配置独立工程，即可停止运行、修改代码并再次执行。

## 使用 npm 包并继续到 IDE

实验过程中可以添加 npm 包、将 fiddle 保存到本地、在常用 IDE 中打开目录，或者加载和发布 GitHub Gist。Lynxtron Go 适合专注的实验与原型；当想法逐渐成长为应用时，可以继续阅读 [Lynxtron 快速上手](/zh/lynxtron/introduction)来创建完整工程。

## 打开文档示例

Lynxtron 文档中的可运行示例提供 **Open in Lynxtron Go** 操作。如果尚未安装 Lynxtron Go，同一个操作会在尝试唤起失败后提供对应的下载入口。
