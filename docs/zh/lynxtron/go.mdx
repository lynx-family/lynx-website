# Lynxtron Go

Lynxtron Go 是 Lynxtron 官方提供的 fiddle 和 playground。无需先创建完整工程，即可编辑、运行和分享小型实验。

- [下载 macOS 版本（Apple 芯片）](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/lynxtron-go-darwin-arm64.dmg)
- [下载 Windows 版本（x64）](https://github.com/lynx-community/lynxtron-examples/releases/latest/download/LynxtronGo-win-x64-Setup.exe)
- [查看全部版本](https://github.com/lynx-community/lynxtron-examples/releases/latest)

Lynxtron Go 的主工作区会在同一窗口中展示应用文件、包模块和进程 Console。

![Lynxtron Go 主工作区，包含应用编辑器、模块和 Console](/assets/lynxtron/go/editor.jpg)

## 从模板或示例开始

点击左上角的新建 fiddle 按钮。选择 **Blank** 创建空白应用边界，选择 **Hello Lynxtron** 创建最小可运行应用，或选择 **Start from a showcase** 进入示例 Gallery。

![选择 Blank 或 Hello Lynxtron，或继续进入示例 Gallery](/assets/lynxtron/go/new-fiddle.jpg)

在 Gallery 中，点击 **Open** 可以将示例载入编辑器，点击 **Run** 可以直接运行，点击 **IDE** 可以在本地编辑器中继续。**Electron Fiddles** 是由 Lynxtron 项目自主维护的示例集合，用于展示 Lynxtron 的桌面 API 和相关能力。

![在内置 Gallery 中浏览可运行的 Lynxtron 示例](/assets/lynxtron/go/showcase-gallery.jpg)

## 同时编辑完整的应用边界

打开 fiddle 后，从 **Editors** 侧边栏选择文件。在 `main.js` 中编辑 Node.js 主进程，在 `renderer.js` 中编辑 Lynx UI，在 `preload.js` 中编辑向 UI 开放的 API，并通过 `styles.css` 和 `package.json` 管理样式与依赖。分栏编辑器可以同时展示这些层，**Modules** 面板则会展示 fiddle 当前可用的包。

## 运行和检查

点击工具栏中的 **Run**，在新的 Lynxtron 进程中启动当前 fiddle。启动后按钮会变为 **Stop**，进程输出会显示在 Lynxtron Go 底部的 Console 中。停止进程、修改文件，再次点击 **Run** 即可重复这一流程。

![Counter fiddle 在独立的 Lynxtron 窗口中运行](/assets/lynxtron/go/run-result.jpg)

## 使用 npm 包并继续到 IDE

在 **Modules** 面板中搜索包，即可将其加入 fiddle。使用 **File > Save** 将 fiddle 保存到本地，使用 **File > Open Folder in IDE** 在常用编辑器中继续，或者通过工具栏中的 Gist 输入框加载和发布 GitHub Gist。Lynxtron Go 适合专注的实验与原型；当想法逐渐成长为应用时，可以继续阅读 [Lynxtron 快速上手](/zh/lynxtron/introduction)来创建完整工程。

## 打开文档示例

在 Lynxtron 文档的可运行示例中，打开启动菜单并选择 **Open in Lynxtron Go**。该操作会将示例 bundle 传递给桌面应用；如果尚未安装 Lynxtron Go，尝试唤起失败后会提供对应的下载入口。
