## 浏览器主线程处理器

每个键对应一个通过 `NativeModules.bridge` 暴露的处理器。处理器在浏览器主线程执行，可使用弹窗、DOM 操作等浏览器 API。处理器可以返回值或 Promise；当前 Web 代理将解析后的结果传给调用方的末尾回调。

处理器接收 UI 传入的参数，模板的 `bridge.call(method, params, callback)` 使用了多参数调用模式。完整 bridge 示例参见[在 Web 中运行 Lynxtron](/lynxtron/learn/running-on-web)。
