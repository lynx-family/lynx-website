# lynx-trace-record

新的 trace 录制流程请使用 [agent-lynx](../agent-lynx/tracing.mdx)。它通过与页面调试相同的 CLI 提供 trace 录制、下载、事件汇总和 SQL 查询。

## 使用 agent-lynx 录制

```bash
npx --yes agent-lynx skills get lynx-devtool
npx --yes agent-lynx trace start --help
```

按照指南选择 client，在打开页面前开始录制，结束后将返回的 stream 下载为 `.pftrace` 文件。

如果已有的 `lynx-trace-record` skill 调用 skill 内的录制脚本，请按照 [agent-lynx 流程](../agent-lynx/tracing.mdx)，改用 `agent-lynx trace start`、`trace end` 和 `trace read-data`。
