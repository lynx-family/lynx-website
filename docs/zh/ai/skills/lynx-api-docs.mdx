# lynx-api-docs

[`@lynx-js/lynx-api-docs`](https://www.npmjs.com/package/@lynx-js/lynx-api-docs) 会把 Lynx 引擎的公开文档和 `using-lynx-api-docs` Agent Skill 安装到项目中。coding agent 可以通过项目本地参考资料了解 Lynx 元素、CSS、布局系统、常用模式、Web 迁移和最佳实践。

适合在以下场景使用：

- 实现或审查 Lynx 页面、模板、组件或样式
- 确认公开元素、属性、CSS 属性、选择器、取值或单位是否受支持
- 在 Linear、Flex、Grid 和 Relative Layout 之间选择合适的布局系统
- 处理 Lynx 与 Web 平台之间的行为差异
- 根据文档排查渲染或样式问题，避免套用通用 Web 知识进行猜测

## 安装

在项目根目录运行：

```bash
npx @lynx-js/lynx-api-docs@latest install
```

安装程序会：

- 将文档复制到 `.ai/lynx-api-docs/`
- 将标准 skill 安装到 `.agents/skills/using-lynx-api-docs/`
- 在保留项目原有说明的前提下，向根目录 `AGENTS.md` 添加受管理的 Lynx API 文档区块
- 默认将 skill 链接到项目本地的 Claude Code、Codex 和 Trae skill 目录

:::info
这个软件包为 coding agent 提供上下文，不是 Lynx 应用的运行时依赖。
:::

如果想先预览文件变更，可以运行：

```bash
npx @lynx-js/lynx-api-docs@latest install --dry-run
```

也可以安装到其他项目，或者跳过面向特定 agent 的链接：

```bash
npx @lynx-js/lynx-api-docs@latest install --project ../my-lynx-app
npx @lynx-js/lynx-api-docs@latest install --no-link
```

## 使用 Skill

兼容的 coding agent 在处理 Lynx 代码时可以自动启用 `using-lynx-api-docs`，也可以在请求中明确指定：

```text
在实现这个组件前，使用 using-lynx-api-docs 确认 <scroll-view>
支持的属性和事件。
```

这个 skill 会要求 agent 在修改 Lynx 代码前读取相关的本地参考资料，并根据任务选择对应文档：

- `elements/<element-name>.md`：元素属性、事件和方法
- `css/`：受支持的属性、选择器、取值、单位和伪类
- `layout/`：Linear、Flex、Grid 和 Relative Layout
- `lynx-vs-web/`：Web 迁移和行为差异
- `patterns/` 和 `best-practices.md`：常用实现建议

## 更新

再次执行安装命令，即可更新受管理的文档、skill、链接和 `AGENTS.md` 区块：

```bash
npx @lynx-js/lynx-api-docs@latest install
```
