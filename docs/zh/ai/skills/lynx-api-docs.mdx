# lynx-api-docs

`lynx-api-docs` Agent Skill 为 coding agent 提供 Lynx 公开元素、CSS、布局系统、常用模式、Web 迁移和最佳实践等项目本地参考资料。这些参考资料来源于 Lynx 引擎的 [`@lynx-js/lynx-api-docs`](https://www.npmjs.com/package/@lynx-js/lynx-api-docs) 软件包。

适合在以下场景使用：

- 实现或审查 Lynx 页面、模板、组件或样式
- 确认公开元素、属性、CSS 属性、选择器、取值或单位是否受支持
- 在 Linear、Flex、Grid 和 Relative Layout 之间选择合适的布局系统
- 处理 Lynx 与 Web 平台之间的行为差异
- 根据文档排查渲染或样式问题，避免套用通用 Web 知识进行猜测

## 安装

```bash
npx skills add lynx-community/skills -s lynx-api-docs
```

该命令会安装 `lynx-api-docs` skill 及其包含的公开 API 参考资料，让兼容的 coding agent 自动加载与当前任务相关的文档。

:::info
这个 skill 为 coding agent 提供上下文，不是 Lynx 应用的运行时依赖。
:::

## 使用 Skill

兼容的 coding agent 在处理 Lynx 代码时可以自动启用 `lynx-api-docs`，也可以在请求中明确指定：

```text
在实现这个组件前，使用 lynx-api-docs 确认 <scroll-view>
支持的属性和事件。
```

这个 skill 会要求 agent 在修改 Lynx 代码前读取相关的本地参考资料，并根据任务选择对应文档：

- `elements/<element-name>.md`：元素属性、事件和方法
- `css/`：受支持的属性、选择器、取值、单位和伪类
- `layout/`：Linear、Flex、Grid 和 Relative Layout
- `lynx-vs-web/`：Web 迁移和行为差异
- `patterns/` 和 `best-practices.md`：常用实现建议

## 更新

再次执行安装命令，即可更新 skill 及其包含的参考资料：

```bash
npx skills add lynx-community/skills -s lynx-api-docs
```
