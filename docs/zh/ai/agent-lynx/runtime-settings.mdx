# 运行时开关

先[连接应用](connections.mdx)，并选择对应的 client ID。

先列出支持的全局开关，再读取或修改某个开关：

```bash
agent-lynx global-switch list --client <clientId>
agent-lynx global-switch get --client <clientId> --key enable_debug_mode
agent-lynx global-switch set --client <clientId> --key enable_debug_mode --status on
```

开关涉及调试、DOM/CSS/Page 域、运行时配置和截图行为。可用键名参见 `global-switch get --help`。修改后若提示重启应用，请按提示操作。
