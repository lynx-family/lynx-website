# Recorder

[Recorder](/guide/devtool/recorder) 用于记录 Lynx 页面的运行时状态，并进行确定性回放。录制文件包含重建页面所需的视图结构、数据状态和运行时输入，便于脱离原始应用环境复现与调试问题。

通过 `agent-lynx recorder` 开始录制并导出 TestBench 回放 JSON 文件。

先[连接应用](connections.mdx)，整个录制过程使用同一个 client ID：

```bash
agent-lynx recorder start --client <clientId>
agent-lynx open '<bundle-url>' --client <clientId>
# 页面达到需要记录的状态后，保存录制数据。
agent-lynx recorder end --client <clientId> -o ./recording.json
```

在**打开或重载页面之前**开始录制，使文件包含回放所需的 `loadTemplate`。如果 `recorder start` 启用了调试模式并要求重启，重启应用后再次运行该命令，再打开页面。`recorder end` 保存数据流、返回文件路径，并检查录制文件是否为空、无效或无法回放。多个 session 可能生成多个文件。

回放和产物托管参见 [Lynx Recorder 指南](/guide/devtool/recorder)。
