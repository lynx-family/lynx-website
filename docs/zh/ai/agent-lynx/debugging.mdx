# 日志与运行时调试

当[页面检查](page-inspection.mdx)发现结果不符合预期时，agent-lynx 可以将页面现象与日志、已加载的脚本和 JavaScript 实时值对应起来，确认代码执行到哪里、收到了什么运行时输入。

## 从加载失败追到运行时配置

下面以 Profile 页面为例：点击 **Load Profile** 后，用户资料没有显示出来。agent 已经[连接应用并选定页面](connections.mdx)，整个排查过程使用同一个 client `android-phone:8901` 和 session `2`。

<AgentConversation locale="zh" {...configurationExample}>

    这次加载在发出请求前就返回了。<code>profile-service.js</code> 中的加载函数在{' '}
    <code>apiBaseUrl</code> 缺失时记录错误并返回；当前后台 VM 中这个字段的值是{' '}
    <code>undefined</code>。
  </p>
  <p>
    需要检查宿主加载该页面时，是否通过 <code>globalProps</code> 传入了有效的{' '}
    <code>apiBaseUrl</code>。补齐后重新加载页面，再核对日志和资料展示结果。
  </p>
</AgentConversation>

日志指出了脚本位置和 VM 线程，读取脚本解释了失败条件，执行表达式则验证了当前页面是否满足这个条件。这里的 `apiBaseUrl` 是示例应用约定的业务字段，由宿主通过 [GlobalProps](/api/lynx-api/lynx/lynx-global-props) 传入。

## 在同一个目标上串联证据

同一个 session 可以包含 `background` 和 `main` 两个 VM。示例日志标为 `background`，因此后续的脚本请求和表达式求值也指向后台 VM。`get-sources` 列出的是后台 VM 中的脚本。

脚本 ID 和远程对象 ID 都属于对应的 client、session 和 VM。例如，日志中包含 `objectId` 时，可以通过 `cdp` 的 `Runtime.getProperties` 在同一目标上读取对象属性。页面重载或切换后，应重新获取日志和脚本 ID 再继续排查。

## 日志与运行时调试能力

| 能力                   | 支持的操作与用途                                                                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 读取与跟踪日志         | `get-console` 读取日志级别、VM 线程和可用的调用栈；watch 模式可以在复现问题时持续跟踪新日志。                                                      |
| 发现运行中的脚本       | `get-sources` 列出后台 VM 中的脚本 URL 和 ID；通过 `cdp` 的 `Debugger.getScriptSource` 读取脚本的运行时代码。                                      |
| 定位元素源码           | 页面提供 [UI source-map 元数据](/guide/devtool/ui-source-map)时，`get-source-info` 可以将新[快照](page-inspection.mdx)中的元素引用映射到源码位置。 |
| 检查 JavaScript 实时值 | `evaluate` 在后台或主线程 VM 中执行表达式，可读取实时值、等待 Promise，或返回远程对象供进一步检查。                                                |
| 打开图形化检查器       | `inspect` 输出检查器 URL，在图形界面中检查选定的 client 和 session。                                                                               |
| 发送页面协议请求       | `cdp` 调用 [Lynx CDP 实现](/api/cdp/api-ref)支持的方法，包括读取脚本源码、检查运行时对象等。                                                       |
| 发送宿主协议请求       | `app` 向选定的 client 发送 App 协议请求，可用方法和参数取决于宿主应用。                                                                            |

日志过滤、输出格式、VM 选择和表达式求值参数见 [CLI 参考](cli-reference.mdx#日志与运行时调试选项)。需要继续检查组件 props、state 和层级关系时，参见 [ReactLynx 组件](reactlynx.mdx)。
