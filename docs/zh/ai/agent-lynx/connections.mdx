# 应用与页面连接

## 连接应用并选择页面

1. 运行 [Lynx Explorer](/guide/start/quick-start)，或已[集成 DevTool](/guide/start/integrate-lynx-devtool) 的应用。
2. 在应用中打开 **Lynx Debug** 和 **Lynx DevTool** 开关。使用真机时，将设备连接到运行 agent-lynx 的电脑，并完成对应平台的调试配置。参见[设备连接说明](/guide/devtool)。
3. 在应用中打开 Lynx 页面，然后查找对应的 client 和 session：

```bash
agent-lynx list-clients
agent-lynx list-sessions --client <clientId>
```

**Client** 是运行中的应用，**session** 是该应用中的 Lynx view 或调试上下文。使用命令实际返回的 ID。存在多个目标时，在后续页面命令中传入 `--client <clientId>` 和 `--session <sessionId>`，确保操作的是目标页面。

设备命令会自动启动共享的本地 connector daemon。页面快照、元素操作和 ReactLynx 检查应使用默认的 daemon 连接，让多次 CLI 调用共享连接和缓存中的元素引用。

## 等待应用连接

使用 `wait-for-client` 等待应用连接，超时和轮询间隔的单位是**秒**：

```bash
agent-lynx wait-for-client --client-name com.lynx.uiapp --timeout 30
```

该命令等待应用连接。等待页面上的文本或元素时，使用[页面等待](page-inspection.mdx#其他操作与等待)，超时单位为毫秒。

## 打开页面

```bash
agent-lynx open '<bundle-url>' --client <clientId>
```

使用应用可访问的 bundle URL，例如项目开发服务器输出的 URL。项目构建或开发服务器需要单独运行。页面跳转后重新查找 session，并刷新页面快照，再使用元素引用。

## 管理 Connector Daemon

```bash
agent-lynx daemon status
agent-lynx daemon start
agent-lynx daemon stop
```

`status` 读取运行中 daemon 的版本和协议信息，不会启动 daemon。管理命令支持 `--port`，默认值为 `21783`。

设备连接默认共享 daemon。显式的直接连接模式支持 Android、iOS、Desktop 和 HDT transport：

```bash
agent-lynx daemon stop
agent-lynx --no-daemon list-clients
```

直接连接同一个目标前先停止 daemon。页面快照及引用操作、`wait`、`screenshot` 和 ReactLynx 命令需要 daemon，请使用默认连接模式。`ADB_SERVER_HOST` 和 `ADB_SERVER_PORT` 仅配置直接连接模式下的 Android ADB，在 daemon 模式中会被忽略。
