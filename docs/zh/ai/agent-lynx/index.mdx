# agent-lynx

[agent-lynx](https://github.com/lynx-community/skills/tree/main/packages/agent-lynx) — **Lynx for your agent**，让你的 AI agent 拥有开发、调试和验证 Lynx 应用所需的知识与工具。

它提供 CLI、带类型的 Connector API、可组合的 CLI API，以及自带的 skills。Agent 可以检查和操作运行中的页面、分析性能与内存、录制页面运行时状态以供回放，并用运行结果验证代码修改。

## 它如何连接应用

Agent 在电脑上调用 CLI，共享的本地 daemon 保持与 Lynx 应用的连接，将命令发给选中的页面，并返回运行结果。应用通过 client 被发现，应用中的页面通过 session 被定位。

## 开始使用

按照[快速开始](getting-started.mdx)安装 agent-lynx，让 agent 读取使用说明并检查第一个页面。编写脚本或集成到其他工具时，参见[程序化 API](programmatic-api.mdx)。

## Skills 与项目上下文

自带的 skills 提供 agent-lynx 使用说明，由 CLI 和 API 执行操作。使用 `agent-lynx skills list` 发现条目，再通过 `agent-lynx skills get <name>` 按任务读取相应说明。[Agent Skills](https://github.com/lynx-community/skills) 还提供 Lynx 开发知识，[AGENTS.md](../agentsmd.mdx) 则提供项目约定。

如果此前使用 `lynx-devtool` 或 skill 内的 trace 脚本，请将 CLI 入口改为 `agent-lynx`，并读取当前的 DevTool 使用说明。[性能 Trace 流程](tracing.mdx)可以替代单独的录制脚本入口。
