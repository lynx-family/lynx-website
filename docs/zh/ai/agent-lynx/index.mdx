# agent-lynx

[agent-lynx](https://github.com/lynx-community/skills/tree/main/packages/agent-lynx) 是连接 AI agent、自动化工具与 Lynx 应用的工具集，提供 CLI、带类型的 Connector API、可组合的 CLI API，以及自带的 skills。Agent 可以检查和操作运行中的页面、分析性能与内存、录制交互，并用运行结果验证代码修改。

## 开始使用

按照[快速开始](getting-started.mdx)安装 agent-lynx，让 agent 读取使用说明并检查第一个页面。编写脚本或集成到其他工具时，参见[程序化 API](programmatic-api.mdx)。

## Skill 和 MCP 集成

自带的 skills 提供 agent-lynx 使用说明，由 CLI 和 API 执行操作。使用 `agent-lynx skills list` 和 `agent-lynx skills get lynx-devtool` 发现和读取说明。[Agent Skills](https://github.com/lynx-community/skills) 还提供 Lynx 开发知识，[AGENTS.md](../agentsmd.mdx) 则提供项目约定。

如果此前使用 `lynx-devtool` 或 skill 内的 trace 脚本，请将 CLI 入口改为 `agent-lynx`，并读取当前的 DevTool 使用说明。[性能 Trace 流程](tracing.mdx)可以替代单独的录制脚本入口。

[Lynx DevTool MCP](../lynx-devtool-mcp.mdx) 通过 MCP 工具提供运行时调试，可根据 agent 的集成方式选择入口。[Lynx Docs MCP](../lynx-docs-mcp.mdx) 可以与任一方式配合，提供文档访问能力。
