# 面向 AI 的 Lynx

为 coding agent 提供 Lynx 项目上下文、开发知识和真实应用的运行结果。以下工具可以配合使用：

| Agent 需要什么                       | 从这里开始                                                      |
| ------------------------------------ | --------------------------------------------------------------- |
| 检查运行中的页面、复现问题或验证修改 | [agent-lynx](agent-lynx.mdx)                                    |
| 项目命令与开发约定                   | [Lynx 下的 AGENTS.md](agentsmd.mdx)                             |
| Lynx 开发模式与最佳实践              | [Agent Skills](https://github.com/lynx-community/skills)        |
| 最新指南与 API 参考                  | [Lynx Docs MCP](lynx-docs-mcp.mdx) 或 [llms.txt](#使用-llmstxt) |

## 使用 agent-lynx 调试和验证

[agent-lynx](agent-lynx.mdx) 将 coding agent 连接到运行中的 Lynx 应用，通过 CLI 提供页面快照、元素交互、截图、控制台与源码检查、ReactLynx 组件检查和性能录制能力。

```bash
npx --yes agent-lynx --help
npx --yes agent-lynx skills get lynx-devtool
npx --yes agent-lynx list-clients
```

按照 [agent-lynx 使用指南](agent-lynx.mdx)连接应用，完成第一次调试。

全部公开能力参见[完整命令与 API 参考](agent-lynx-reference.mdx)，包括交互录制、堆快照、全局开关及 CLI 集成。

## 使用 `AGENTS.md` 配置项目

[`AGENTS.md`](https://agents.md) 类似于 `README.md`，但面向 coding agent 编写。它为 agent 提供在 Lynx 代码库中高效工作所需的项目级上下文，无需任何依赖即可立即生效。

在 [Lynx 下的 AGENTS.md](agentsmd.mdx) 中了解如何为你的 Lynx 项目添加合适的 `AGENTS.md`。

## 使用 Agent Skills 添加领域知识

[Agent Skills](https://agentskills.io/home) 是可复用的规则集，为 coding agent 提供关于 Lynx 双线程架构、常见模式和调试技巧的领域知识。使用以下命令安装社区集合：

```bash
npx skills add lynx-community/skills
```

在 [Lynx Agent Skills](https://github.com/lynx-community/skills) 中了解更多信息。

## 使用 MCP 读取文档

[Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) 是一个连接 coding agent 与外部工具的标准。

[**Lynx Docs MCP**](lynx-docs-mcp.mdx) 让 agent 直接从 Lynx 文档站点获取指南和 API 参考。需要同时查阅文档和检查运行结果时，将它与 agent-lynx 配合使用。

已有集成或必须通过 MCP 工具进行运行时调试的客户端，仍可参考 [Lynx DevTool MCP](lynx-devtool-mcp.mdx)。

## 使用 `llms.txt`

Lynx 网站还支持 [llms.txt](https://llmstxt.org/) 标准，适合将 Lynx 文档提供给任何具有网页浏览功能的大语言模型。对于每个页面，你可以通过将 `.html` 扩展名替换为 `.md` 来获取原始 Markdown。例如：

- [https://lynxjs.org/llms.txt](https://lynxjs.org/llms.txt)
- [https://lynxjs.org/react/introduction.md](https://lynxjs.org/react/introduction.md)

## 生成式 UI

除了用 AI 帮助开发者写 Lynx 代码，Lynx 也支持 AI Agent 在运行时通过开发者控制的组件生成界面。ReactLynx 目前提供两种接入方式：

- [A2UI](/react/genui/a2ui) 渲染由 Google 发起的 Agent-to-UI 开放协议消息。阅读 [A2UI 驱动的 Lynx 生成式界面](/blog/lynx-a2ui)了解发布详情。
- [OpenUI](/react/genui/openui) 把紧凑、可流式传输的 OpenUI Lang 渲染为原生界面，并提供响应式状态、工具调用和可扩展的组件库。
