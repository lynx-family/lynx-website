# Platform Artwork

These existing glyphs were moved from the compatibility table so shared
platform UI does not depend on that table's implementation. Keep one canonical
copy for platform headers, badges, tabs, and homepage indicators.

Original SVG attribution comments are preserved. These assets retain the
compatibility table's [MPL-2.0 license](../../api-table/compat-table/LICENSE).
The platform-name normalization helper also retains its Mozilla notice.

Domain illustrations remain with their own components. The public Lynxtron
icon URL and public assets used by downstream consumers remain unchanged.
