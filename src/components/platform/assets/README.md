# Platform Glyphs

These mask glyphs belong to the shared platform renderer so platform headers,
badges, tabs, and homepage indicators do not depend on another domain's
implementation.

Original SVG attribution comments are preserved. These assets retain the
compatibility table's [MPL-2.0 license](../../api-table/compat-table/LICENSE).
The platform glyph resolver also retains its Mozilla notice.

Domain illustrations remain with their own components. `lynxtron.svg` is the
private mask copy used by `PlatformIcon`; the existing light/dark public
Lynxtron URLs remain unchanged for theme and downstream consumers.
